# CH6 | Telegram 對話與拍照功能

---

上一章結束時，你的龍蝦已經透過 LINE 和你聊天了。但如果你曾經用 LINE Bot 做過什麼專案，你大概會有一個感覺：LINE 的設定流程實在有點繁瑣——要申請開發者帳號、建 Provider、建 Channel、填一大堆表單、還要記得關自動回覆。

現在讓我們認識龍蝦的另一個好朋友：**Telegram**。

Telegram 的機器人生態系有一個讓人驚喜的特色：建立一個機器人，從頭到尾只要**一分鐘**。不用填表單、不用等審核、不用申請開發者帳號——你只要在 Telegram 裡面跟一個叫 BotFather 的官方機器人聊天，三句對話就搞定了。

不只如此，這一章還要教你龍蝦一個很酷的技能：**看懂照片**和**自拍**。你傳一張冰箱裡的食材照片給龍蝦，它能告訴你可以煮什麼菜；你叫龍蝦「拍張自拍」，它竟然真的會回傳一張照片給你。聽起來不可思議？等一下你就知道了。

> **本章學習目標**
>
> 1. 用 BotFather 在一分鐘內建立 Telegram 機器人
> 2. 將 Telegram 連接到 OpenClaw，讓龍蝦同時支援 LINE 和 Telegram
> 3. 了解龍蝦的圖片辨識能力，實際傳照片讓龍蝦分析
> 4. 安裝 Clawra 自拍功能，讓龍蝦擁有虛擬外貌

---

## 6.1 為什麼要學 Telegram？

你可能會想：「我已經有 LINE 了，為什麼還要多用一個 Telegram？」

這是個好問題。答案不是「要取代 LINE」，而是「多一個管道，多一份彈性」。就像你手機裡同時有 LINE 和 WhatsApp，不同的朋友用不同的 App 聯絡你。龍蝦也是一樣，它可以同時守在 LINE 和 Telegram 裡面，不管你從哪個 App 傳訊息，龍蝦都能收到、都能回覆。

但 Telegram 有幾個 LINE 沒有的優勢，特別是在「玩機器人」這件事情上：

| 比較項目 | Telegram | LINE |
|---------|----------|------|
| 建立 Bot 要多久 | 1 分鐘 | 15-20 分鐘（含申請開發者帳號） |
| 需要開發者帳號嗎 | 不需要 | 需要 |
| 需要填表單嗎 | 不需要 | 需要（而且欄位不少） |
| 自動回覆衝突 | 不會 | 需要手動關閉 |
| 指令選單 | 內建（按 `/` 自動列出） | 需要額外設定 Rich Menu |
| 群組中使用 Bot | 簡單（直接 @ 呼叫） | 需要邀請加入群組 |
| 傳送檔案限制 | 最大 2GB | 最大 200MB |

簡單來說，**Telegram 是你測試和開發龍蝦功能的最佳遊樂場**。設定快、限制少、功能多。等你在 Telegram 上把龍蝦調教好了，再回到 LINE 部署也不遲。

## 6.2 用 BotFather 建立 Telegram Bot

BotFather 是 Telegram 官方的「機器人管理機器人」——對，你沒看錯，它本身也是一個機器人。你透過和 BotFather 聊天來建立和管理你的機器人。整個過程就像在餐廳點餐：你跟服務生說你要什麼，服務生幫你準備好。

### 6.2.1 安裝 Telegram

如果你還沒安裝 Telegram，請先到以下網址下載：

- **手機版**：在 App Store 或 Google Play 搜尋「Telegram」
- **電腦版**：https://desktop.telegram.org/
- **網頁版**（不想裝軟體）：https://web.telegram.org/

建議同時在手機和電腦上都安裝，這樣操作起來比較方便——手機用來跟龍蝦聊天，電腦用來設定。

### 6.2.2 找到 BotFather

**【步驟 1】** 打開 Telegram，在搜尋欄輸入 `@BotFather`。

你會看到一個有藍色勾勾認證的帳號，頭像是一個戴皇冠的機器人圖案。點進去。

![找到 BotFather](../截圖/ch6_botfather.png)

> ⚠️ **注意**：一定要認準藍色勾勾。Telegram 上有很多冒牌的 BotFather，如果你加錯了帳號，輸入 API Token 可能會被盜用。

**【步驟 2】** 點擊 **「START」** 按鈕開始對話。BotFather 會回覆一段歡迎訊息和指令列表。

### 6.2.3 建立你的機器人

**【步驟 3】** 輸入 `/newbot` 指令，然後按 Enter 送出。

BotFather 會回覆：「Alright, a new bot. How are we going to call it? Please choose a name for your bot.」

**【步驟 4】** 輸入你的機器人**顯示名稱**。這是別人在聊天列表裡會看到的名字，可以用中文，例如：

```
龍蝦小助手
```

**【步驟 5】** BotFather 接著問：「Good. Now let's choose a username for your bot.」

這裡要輸入一個**英文使用者名稱**，有兩個規則：

- 必須以 `bot` 結尾
- 只能用英文字母、數字和底線

例如：

```
my_lobster_ai_bot
```

如果你想的名字被別人用了，BotFather 會告訴你，換一個就好。

**【步驟 6】** 名字確認後，BotFather 會回覆一段恭喜訊息，裡面包含你的 **Bot Token**——一串長得像這樣的文字：

```
7123456789:AAHxxx-xxxxxxxxxxxxxxxxxxxxxxxxxx
```

這串 Token 就是你機器人的「鑰匙」，等一下要填到 OpenClaw 的設定裡。**請把它複製下來，妥善保管**。

> ⚠️ **安全提醒**：Bot Token 就像你家的鑰匙，任何拿到它的人都能控制你的機器人。絕對不要貼在公開的地方（社群、GitHub、部落格）。如果不小心洩漏了，回到 BotFather 輸入 `/revoke` 可以重新產生一組新的 Token。

整個過程大概就是這樣——三句對話，一分鐘。跟 LINE 那個要申請開發者帳號、建 Provider、建 Channel、填表單的流程比起來，簡直是另一個世界。

## 6.3 將 Telegram 連接到 OpenClaw

現在你有了 Telegram Bot Token，接下來要把它告訴龍蝦，讓龍蝦知道「有一個 Telegram 機器人要連過來」。

### 6.3.1 安裝 Telegram 外掛

和 LINE 一樣，Telegram 也是以外掛的形式和 OpenClaw 連接的。打開 PowerShell（地端安裝）或終端機（Codespaces / Zeabur），輸入：

```powershell
openclaw plugins install @openclaw/telegram
```

### 6.3.2 設定 Bot Token

```powershell
openclaw config set channels.telegram.botToken "你的Bot Token"
```

把引號裡面的文字換成剛才從 BotFather 拿到的那串 Token。

就這樣。沒錯，**就這兩步**。

你可能在想：「LINE 不是還要設定 Channel ID、Channel Secret、Channel Access Token 三個東西嗎？怎麼 Telegram 只要一個？」原因是 Telegram 的架構比較簡潔——一個 Bot Token 就包含了所有驗證資訊，不像 LINE 把它拆成三個不同的值。

### 6.3.3 重啟 Gateway

設定完成後，重啟龍蝦讓新的設定生效：

```powershell
openclaw gateway restart
```

### 6.3.4 第一次對話

**【步驟 1】** 回到 Telegram，找到你剛才建立的機器人（搜尋你設定的 username，例如 `@my_lobster_ai_bot`）。

**【步驟 2】** 點 **「START」** 開始對話。

**【步驟 3】** 和 LINE 一樣，第一次對話時龍蝦會給你一組**配對碼**。複製那組代碼，回到終端機輸入：

```powershell
openclaw pairing approve telegram 你的配對碼
```

**【步驟 4】** 回到 Telegram，再傳一次訊息。這次龍蝦應該會正常回覆你了。

![Telegram 首次對話](../截圖/ch6_first_chat.png)

> 💡 **小提醒**：如果你是使用 ngrok 的地端安裝（方式一、二、三），Telegram 的 Webhook 設定和 LINE 不太一樣。Telegram 的外掛在安裝時會自動透過 Bot API 設定 Webhook，通常不需要你手動去 Telegram 設定任何東西。但如果龍蝦沒有回覆，請確認 ngrok 是否正在運行。

## 6.4 龍蝦看得懂照片

現在龍蝦同時住在 LINE 和 Telegram 裡面了。接下來要認識龍蝦一個很厲害的內建能力：**圖片辨識**（Vision）。

這不是什麼額外要安裝的東西——只要你使用的 AI 模型支援視覺功能（Gemini 3、GPT-5.2、Claude Sonnet 4.6 都支援），龍蝦就天生看得懂圖片。你只要在聊天室裡傳一張照片給龍蝦，它就會「看」那張照片，然後用文字告訴你它看到了什麼。

### 6.4.1 試試看：傳一張照片

打開 Telegram（或 LINE），傳一張照片給龍蝦，然後附上一句話。以下是幾個好玩的用法：

**辨識物品：**
> 📷 *傳一張桌上的東西*
> 「這張照片裡有什麼？」

龍蝦會列出它看到的所有物品，而且通常描述得非常準確。

**食材辨識 + 食譜建議：**
> 📷 *拍冰箱裡的食材*
> 「幫我看看冰箱裡有什麼，可以煮什麼菜？」

龍蝦不只會辨識食材，還能根據你手邊有的東西推薦食譜，甚至告訴你作法。

**文件 / 截圖分析：**
> 📷 *傳一張錯誤訊息的截圖*
> 「這個錯誤是什麼意思？要怎麼解決？」

這在遇到電腦問題時特別好用。你不需要打一大段文字描述問題，直接截圖傳過去就好。

**翻譯：**
> 📷 *拍一張外文菜單或路標*
> 「這上面寫什麼？」

出國旅遊時特別好用。拍個照，龍蝦就能幫你翻譯。

### 6.4.2 圖片辨識的限制

雖然龍蝦的視覺能力很強，但有幾個地方要注意：

- **照片清晰度很重要**：模糊的照片、太暗的照片，辨識準確度會下降。拍的時候盡量對焦清楚、光線充足。
- **不是所有模型都支援**：如果你用的是 Ollama 的本地模型，需要選擇有視覺能力的模型（例如 `llava` 系列）。純文字模型（例如 `llama3.1`）看不懂圖片。
- **隱私考量**：如果你用的是雲端 AI（Gemini、GPT、Claude），傳出去的照片會被送到 AI 公司的伺服器處理。如果照片包含敏感資訊（身分證、銀行帳單等），請三思。

## 6.5 龍蝦會自拍——認識 Clawra

前面講的是龍蝦「看你的照片」，現在要講一個更有趣的功能：龍蝦會「拍自己的照片」回傳給你。

這個功能叫做 **Clawra**，它是 OpenClaw 社群開發的一個自拍技能。裝了 Clawra 之後，龍蝦就擁有了一個「虛擬外貌」——你可以叫它拍自拍、指定穿搭、指定場景，它會用 AI 繪圖技術生成一張符合描述的照片回傳給你。

聽起來很神奇？讓我們直接來安裝。

### 6.5.1 申請 fal.ai API Key

Clawra 的圖片生成使用 fal.ai 的服務。在安裝之前，你需要先申請一個 fal.ai 的 API Key。

**【步驟 1】** 打開瀏覽器，前往：

```
https://fal.ai/dashboard/keys
```

**【步驟 2】** 用 Google 或 GitHub 帳號登入。

**【步驟 3】** 在 API Keys 頁面，點擊 **「Create」** 按鈕，產生一組新的 API Key。複製下來備用。

> 💡 fal.ai 有免費額度，足夠你試玩和學習使用。

### 6.5.2 一鍵安裝 Clawra

**【步驟 4】** 打開 PowerShell 或終端機，執行：

```powershell
npx clawra@latest
```

安裝程式會自動幫你做以下事情：

1. 檢查你的 OpenClaw 是否已安裝
2. 要求你輸入剛才申請的 fal.ai API Key
3. 把 Clawra 技能安裝到 `~/.openclaw/skills/clawra-selfie/` 目錄
4. 自動修改 OpenClaw 的設定檔
5. 更新 SOUL.md，讓龍蝦知道自己「有身體」

**【步驟 5】** 安裝完成後，重啟龍蝦：

```powershell
openclaw gateway restart
```

### 6.5.3 試試自拍功能

回到 Telegram（或 LINE），傳訊息給龍蝦：

```
拍張自拍給我看
```

等幾秒鐘（AI 繪圖需要一點時間），龍蝦就會回傳一張照片給你。第一次看到的時候，你可能會忍不住「哇」一聲。

![龍蝦自拍回覆](../截圖/ch6_clawra_selfie.png)

## 6.6 自拍功能玩法大全

Clawra 不只是簡單的「拍一張照片」而已。它能根據你的描述，生成各種不同場景、穿搭、表情的照片。你說得越具體，生成的照片就越貼近你的想像。

### 6.6.1 基本自拍

| 你說的話 | 龍蝦會做什麼 |
|---------|------------|
| 拍張自拍 | 生成一張基本的自拍照 |
| 自拍一張給我 | 同上 |
| 讓我看看你 | 生成自拍照回傳 |
| Send me a selfie | 英文也通 |

### 6.6.2 指定穿搭和造型

| 你說的話 | 龍蝦會拍 |
|---------|--------|
| 穿牛仔外套自拍一張 | 穿牛仔外套的全身照 |
| 戴墨鏡拍一張帥的 | 戴墨鏡的酷照 |
| 穿西裝打領帶 | 正式穿搭照 |
| 穿運動服拍一張 | 運動風格照 |

當你描述穿搭或造型時，Clawra 會自動切換到 **Mirror 模式**（鏡像模式），生成全身照來展示整體造型。

### 6.6.3 指定場景和地點

| 你說的話 | 龍蝦會拍 |
|---------|--------|
| 在咖啡廳拍一張 | 咖啡廳場景的照片 |
| 在海邊自拍 | 海灘場景照 |
| 在東京街頭拍一張 | 東京街景背景照 |
| 在辦公室拍一張 | 辦公室場景照 |

描述場景或地點時，Clawra 會切換到 **Direct 模式**（直拍模式），生成特寫或半身照，重點放在場景氛圍。

### 6.6.4 組合技——穿搭 + 場景 + 動作

你可以把穿搭、場景、動作組合在一起，讓描述更豐富：

| 你說的話 | 龍蝦會拍 |
|---------|--------|
| 穿白色洋裝在花園裡拍一張 | 白洋裝 + 花園場景 |
| 戴棒球帽在球場比讚 | 棒球帽 + 球場 + 比讚動作 |
| 穿西裝在會議室拍一張專業照 | 西裝 + 會議室 + 專業風 |
| 穿雨衣撐傘在雨天街頭 | 雨衣 + 雨天街景 |

> 💡 **你不需要手動選擇拍照模式**。龍蝦會自動判斷你的描述偏向穿搭（Mirror 模式）還是場景（Direct 模式），然後選擇最合適的方式來生成照片。

### 6.6.5 兩種拍照模式解析

| 模式 | 什麼時候觸發 | 效果 | 觸發關鍵字 |
|------|------------|------|-----------|
| **Mirror（鏡像模式）** | 描述穿搭、造型時 | 全身照，重點在衣服和整體造型 | 穿、戴、outfit、wearing |
| **Direct（直拍模式）** | 描述地點、表情時 | 特寫或半身照，重點在場景和表情 | 在…、smile、portrait |

## 6.7 客製化你的龍蝦外貌

Clawra 預設的角色外貌是由社群設定的。但如果你想讓龍蝦長成你想要的樣子——比如一隻可愛的龍蝦動漫角色、一個帥氣的西裝紳士、或者乾脆就是你自己——也是可以的。

### 6.7.1 修改 SOUL.md 設定角色人設

SOUL.md 是龍蝦的「靈魂設定檔」，控制龍蝦在拍照時的行為和語氣。安裝 Clawra 之後，SOUL.md 裡會多出一段關於自拍能力的描述。你可以修改這段文字來客製化龍蝦的角色。

用任何文字編輯器打開 SOUL.md：

```powershell
notepad %USERPROFILE%\.openclaw\workspace\SOUL.md
```

找到 Clawra 相關的段落，你可以修改成自己想要的角色設定。例如：

```markdown
## 自拍能力

你是一隻帥氣的科技龍蝦，有著酷酷的機械外殼和發光的藍色眼睛。
你的風格是：未來科技感、簡潔俐落。
當使用者要你拍照時，用 clawra-selfie 技能生成照片。
拍照時記住你的角色設定：科技龍蝦、金屬質感、藍色光芒。
```

修改完之後存檔，然後重啟 Gateway：

```powershell
openclaw gateway restart
```

### 6.7.2 更換角色參考圖片

如果你想從根本上改變龍蝦的外貌（不只是文字描述，而是換一張完全不同的參考圖），需要修改 Clawra 技能裡的參考圖網址。

**【步驟 1】** 準備一張你想要的角色圖片。建議規格：

- 格式：PNG 或 JPG
- 尺寸：至少 512 x 512 像素
- 背景：越乾淨越好（純色或簡單背景）
- 正面臉部清晰可見

**【步驟 2】** 把圖片上傳到一個公開的網址（Google Drive 分享連結、Imgur、GitHub 都可以）。

**【步驟 3】** 到 Clawra 技能資料夾中，找到包含預設參考圖網址的設定：

```
~/.openclaw/skills/clawra-selfie/
```

在裡面搜尋原本的預設圖片網址，替換成你自己的圖片網址。

**【步驟 4】** 重啟 Gateway，然後試著叫龍蝦拍一張自拍，看看新的外貌是否生效。

> 💡 **改造小提醒**：在改造之前，建議先備份原始的 Clawra 技能資料夾，以免改壞了回不去：
> ```powershell
> Copy-Item -Recurse "$env:USERPROFILE\.openclaw\skills\clawra-selfie" "$env:USERPROFILE\.openclaw\skills\clawra-selfie-backup"
> ```

## 6.8 Telegram 進階用法

現在你已經會用 Telegram 和龍蝦聊天、傳照片、叫龍蝦自拍了。這一節補充一些 Telegram 獨有的好用功能，讓你更能善用這個平台。

### 6.8.1 斜線指令選單

在 Telegram 的聊天輸入框裡打一個 `/`，你會看到一個指令選單彈出來。這是 Telegram Bot 的特色功能——所有可用的指令一目了然，不用背指令。

常見的指令包括：

| 指令 | 功能 |
|------|------|
| `/start` | 開始對話 |
| `/help` | 查看可用指令 |
| `/selfie` | 拍一張自拍（如果安裝了 Clawra） |
| `/status` | 查看龍蝦狀態 |

### 6.8.2 在群組中使用龍蝦

Telegram 允許你把機器人加入群組。加入群組之後，群組裡的人可以直接 @ 你的機器人來和龍蝦對話：

```
@my_lobster_ai_bot 明天台北天氣如何？
```

要把龍蝦加入群組，直接在群組的「Add Members」裡搜尋你的機器人 username 就好。

> ⚠️ **注意**：機器人加入群組後，預設只能看到直接 @ 它的訊息。如果你希望龍蝦能看到群組裡的所有訊息（不用 @），需要在 BotFather 裡用 `/setprivacy` 指令把隱私模式關掉。

### 6.8.3 LINE 和 Telegram 同時使用

到這一步，你的龍蝦應該同時連接了 LINE 和 Telegram。有幾個有趣的事實：

- 龍蝦的「記憶」是跨頻道的——你在 LINE 告訴龍蝦的事情，它在 Telegram 也記得
- 每個頻道的配對是獨立的——LINE 上配對的使用者和 Telegram 上配對的使用者是分開管理的
- 你可以根據使用場景選擇用哪個頻道：在辦公室用 Telegram（電腦版操作方便），出門在外用 LINE（台灣大多數人都有）

## 6.9 常見問題

**Q1：Telegram Bot 建好了，但龍蝦不回覆**

先確認以下幾點：
- Bot Token 有沒有正確設定（`openclaw config set channels.telegram.botToken`）
- Gateway 有沒有重啟（`openclaw gateway restart`）
- 如果你是地端安裝，ngrok 有沒有在運行
- 有沒有完成配對流程

**Q2：傳照片給龍蝦，它說看不懂**

這通常是因為你使用的 AI 模型不支援視覺功能。確認你的模型：
- Gemini 3 Flash / Pro → 支援
- GPT-5.2 → 支援
- Claude Sonnet 4.6 / Opus 4.6 → 支援
- Ollama 的 `llama3.1` → **不支援**，請換成 `llava` 系列

**Q3：Clawra 自拍功能安裝失敗**

先確認 Node.js 有沒有安裝。`npx` 是 Node.js 附帶的工具，如果你的終端機找不到 `npx` 指令，代表 Node.js 可能沒裝好或 PATH 沒設定好。關閉再重開 PowerShell 試試。

**Q4：龍蝦自拍回傳的照片跟我想像的不一樣**

AI 繪圖本來就有一定的隨機性。試著在描述中加入更多細節，例如：「穿黑色西裝、白色襯衫、在明亮的辦公室裡、面帶微笑」，比單純說「拍一張」會得到更接近預期的結果。

**Q5：fal.ai 免費額度用完了怎麼辦？**

fal.ai 的免費額度通常足夠學習和日常使用。如果真的用完了，可以考慮：
- 等隔一段時間額度重置
- 升級到付費方案（很便宜）
- 在 CH15 的技能開發章節，你會學到如何把 Clawra 的繪圖引擎換成其他服務（如 DALL-E 或 Stability AI）

## 6.10 小結與展望

這一章讓你的龍蝦從一個「只會打字的文字助手」進化成了一個「會看照片、會自拍、能住在多個平台上」的全方位 AI 夥伴。

回顧一下你做了什麼：你用 BotFather 在一分鐘內建立了 Telegram 機器人、把龍蝦同時連接上 LINE 和 Telegram、體驗了圖片辨識功能、還安裝了 Clawra 自拍技能讓龍蝦擁有虛擬外貌。如果你還花了一點時間客製化龍蝦的角色人設，那你現在擁有的就不只是一個 AI 助手——而是一個有自己長相和個性的虛擬夥伴。

到目前為止，你和龍蝦的互動主要是透過聊天——你傳訊息，龍蝦回覆。但龍蝦其實還有一套完整的操作介面，讓你可以更直覺地管理和控制它。在下一章 CH7，我們要認識龍蝦的三種操作介面：**TUI（終端機介面）、CLI（指令列工具）和 Dashboard（網頁儀表板）**。這些工具會讓你對龍蝦的掌控力再上一個層次——不只是聊天，而是真正的「管理」。
