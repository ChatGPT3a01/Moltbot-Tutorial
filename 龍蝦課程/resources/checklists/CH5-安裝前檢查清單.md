# CH5 安裝前檢查清單

開始安裝 OpenClaw 之前，確認以下項目。

---

## 系統需求

| # | 項目 | 完成 | 說明 |
|---|------|------|------|
| 1 | Windows 10/11 或 Mac/Linux | ☐ | `winver` 確認版本 |
| 2 | Node.js 22+ 已安裝 | ☐ | `node -v` 確認 |
| 3 | npm 可用 | ☐ | `npm -v` 確認 |
| 4 | 網路連線正常 | ☐ | |
| 5 | PowerShell 可用 | ☐ | Windows 內建 |

## 帳號資料已備齊

| # | 項目 | 完成 |
|---|------|------|
| 6 | LINE Channel ID / Secret / Token | ☐ |
| 7 | 至少一組 AI API Key | ☐ |
| 8 | ngrok Authtoken | ☐ |

## 選擇安裝方式

| 方式 | 適合誰 | 你的選擇 |
|------|--------|---------|
| 自動安裝程式 | 新手（推薦） | ☐ |
| 手動 npm 安裝 | 進階用戶 | ☐ |
| Ollama 本地免費 | 有好顯卡、重視隱私 | ☐ |
| GitHub Codespaces | 不想裝在本機 | ☐ |
| Zeabur 一鍵部署 | 最簡單的雲端方案 | ☐ |

## 安裝後驗證

| # | 項目 | 完成 |
|---|------|------|
| 9 | `openclaw doctor` 全部通過 | ☐ |
| 10 | Gateway 啟動成功 | ☐ |
| 11 | ngrok 或 Tunnel 連線成功 | ☐ |
| 12 | LINE Webhook 設定完成 | ☐ |
| 13 | LINE 上傳送訊息有收到回覆 | ☐ |
