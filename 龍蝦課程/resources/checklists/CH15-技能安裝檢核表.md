# CH15 技能安裝檢核表

安裝新技能時，依此表確認每一步。

---

## 安裝流程

| # | 步驟 | 完成 |
|---|------|------|
| 1 | 用 `clawdhub search <名稱>` 找到技能 | ☐ |
| 2 | 用 `clawdhub install <名稱>` 安裝 | ☐ |
| 3 | 用 `openclaw skills list` 確認出現 ✅ | ☐ |
| 4 | 檢查技能的 SKILL.md 看需要什麼設定 | ☐ |
| 5 | 在 TOOLS.md 裡填入需要的 API Key 和設定 | ☐ |
| 6 | `openclaw gateway restart` 重啟 | ☐ |
| 7 | 在 LINE 上測試技能功能 | ☐ |
