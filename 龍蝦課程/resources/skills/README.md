## 🆕 五大自媒體實戰 Skills

這五個技能專為自媒體創作者、線上教育者、品牌經營者設計，複製 SKILL.md 到 workspace 即可使用：

| 技能 | 一句話說明 | 你會得到 |
|------|----------|---------|
| content-creator | 說一個主題，拿到完整文章 | SEO 文章、IG 貼文、Hook 金句 |
| video-script | 說主題和長度，拿到完整腳本 | 分鏡表、SRT 字幕、直播流程 |
| course-creator | 說想教什麼，拿到整門課 | 課程大綱、教學腳本、銷售頁 |
| brand-builder | 說你的專業，拿到品牌藍圖 | SWOT 分析、內容日曆、變現計畫 |
| community-manager | 設好規則，24 小時自動經營 | 自動歡迎、FAQ 回覆、私訊分流 |
