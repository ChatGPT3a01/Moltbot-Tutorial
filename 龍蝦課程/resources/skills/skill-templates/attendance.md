# Attendance（學生出缺席管理）

目標：幫老師記錄班上學生的出缺席狀況，並能查詢統計資料。

## 功能

1. 記錄學生的出缺席（出席、請假、遲到、曠課）
2. 查詢某位學生的出缺席紀錄
3. 查詢某天的全班出缺席狀況
4. 統計一段時間內的出缺席報表

## 使用方式

使用者可能會這樣說：
- 「今天王小明請假」
- 「記錄一下，李小華遲到」
- 「張大偉這個月的出缺席紀錄」
- 「今天有誰請假？」
- 「這週的出缺席統計」

## 資料儲存

所有紀錄存在工作區的 `data/attendance/` 資料夾裡：
- 每天一個檔案：`data/attendance/2026-03-07.md`
- 格式：

```
# 2026-03-07（五）出缺席紀錄

| 學生 | 狀態 | 備註 |
|------|------|------|
| 王小明 | 請假 | 感冒 |
| 李小華 | 遲到 | 遲到 10 分鐘 |
```

## 執行方式

### 記錄出缺席
1. 從使用者的訊息中提取：學生姓名、狀態（出席/請假/遲到/曠課）、備註
2. 檢查 `data/attendance/` 資料夾是否存在，不存在就建立
3. 開啟或建立今天的檔案（以日期命名）
4. 新增一筆紀錄到表格裡
5. 回覆確認

### 查詢紀錄
1. 從使用者的訊息中判斷要查什麼（某人、某天、某段時間）
2. 讀取對應的檔案
3. 整理成易讀的格式回覆

### 統計報表
1. 讀取指定時間範圍的所有檔案
2. 統計每位學生的出席、請假、遲到、曠課次數
3. 用表格格式回覆

## 安全原則

- 不要刪除已有的紀錄，只能新增和修改
- 修改紀錄時要先跟使用者確認
- 學生的個人資料不要在群組中揭露
