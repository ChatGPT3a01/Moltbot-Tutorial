## Desktop Agent 安全規則

### 可以自由操作的區域
- 桌面（Desktop）
- 文件資料夾（Documents）
- 下載資料夾（Downloads）
- 工作區（~/.openclaw/workspace/）

### 需要確認才能操作的區域
- 其他磁碟（D:、E: 等）
- 應用程式資料夾
- 外接硬碟和 NAS

### 絕對不能碰的區域
- Windows 系統目錄（C:\Windows\）
- Program Files
- 其他使用者的資料夾
- 任何含有密碼或金鑰的檔案（.env, credentials.json 等）

### 操作規則
- 刪除檔案一律移到資源回收桶（trash），不永久刪除（rm）
- 移動或重新命名超過 5 個檔案時，先列出清單請使用者確認
- 修改任何文件內容前，先跟使用者確認
- 瀏覽器操作在沙盒中進行，不影響使用者的真實瀏覽器
- 所有操作記錄在日誌中，供使用者回顧

### 不允許的操作
- 不自動登入任何帳號（銀行、社群、Email 等）
- 不操作密碼管理器
- 不在沒有確認的情況下安裝或移除軟體
- 不修改系統設定（防火牆、登錄檔等）
