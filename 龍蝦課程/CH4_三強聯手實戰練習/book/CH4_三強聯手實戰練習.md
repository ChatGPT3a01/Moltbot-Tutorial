# CH4 | 三強聯手實戰練習

---

在前面三章裡，你分別認識了 OpenClaw 的概念、學會了 Antigravity 的操作、也上手了 Claude Code 的對話式指令。如果把這三章比喻成學游泳，那你到目前為止做的事情是：認識了水性（CH0）、練了自由式的手部動作（CH2）、練了蛙式的踢腿（CH3）。

但你還沒有真正跳進水裡游過。

這一章就是你的「下水時刻」。我們要做一個完整的實戰專案，把 Antigravity 和 Claude Code 結合起來使用——就像在真實的工作場景中一樣，兩個工具各自發揮所長、分工合作。而且這個專案不是隨便挑的練習題，它會直接為你在 CH5 安裝 OpenClaw 做好準備。

我們要做什麼呢？我們要打造一個**「龍蝦 AI 個人檔案產生器」**——一個漂亮的網頁工具，讓你填入龍蝦的名字、個性、技能等資訊，按下按鈕之後自動產生龍蝦的設定檔。做完這個專案，你不但會更熟練兩個 AI 工具的操作，還會拿到一份可以直接用在安裝龍蝦時的設定檔。

一石二鳥，開始吧。

## 4.1 專案規劃

---

好的工程師在動手之前都會先規劃。即使我們用的是 AI 工具，花一分鐘想清楚「要做什麼」，還是會讓過程順暢很多。

### 4.1.1 我們要做什麼

**「龍蝦 AI 個人檔案產生器」** 是一個單頁網頁應用，功能很簡單：

1. 使用者在網頁上填寫龍蝦的基本資料（名字、個性、說話風格等）
2. 按下「產生」按鈕
3. 網頁自動生成一份 IDENTITY.md 格式的設定檔
4. 使用者可以複製這份設定檔，之後安裝龍蝦時直接使用

> 💡 **什麼是 IDENTITY.md？** 這是 OpenClaw 的「身分證」檔案。它定義了龍蝦的名字、個性、說話風格、回答規則等等。有了這份檔案，龍蝦才知道自己「是誰」。我們在 CH8 會深入介紹，但先在這裡幫你產生一份基本版。

### 4.1.2 分工計畫

在這個專案中，兩個 AI 工具的分工如下：

| 工具 | 負責的事情 | 為什麼用它 |
|------|-----------|-----------|
| **Antigravity** | 製作網頁介面（HTML + CSS + JavaScript） | 有即時預覽，適合「建造」 |
| **Claude Code** | 管理資料夾結構、Git 版本控制、微調設定檔 | 快速精準，適合「操作」 |

實際的工作流程是這樣的：

```
步驟 1：Claude Code 建立專案資料夾和基本結構
         ↓
步驟 2：Antigravity 製作網頁介面和互動功能
         ↓
步驟 3：Claude Code 微調產生的設定檔格式
         ↓
步驟 4：Claude Code 用 Git 保存版本
         ↓
步驟 5：測試整個流程，確認產出的 IDENTITY.md 正確
```

## 4.2 步驟一：用 Claude Code 建立專案骨架

---

我們先用 Claude Code 把專案的資料夾結構搭好。就像蓋房子先打地基一樣，有了清楚的結構，後面 Antigravity 做起來會更順利。

### 【步驟 1】開啟 Claude Code

打開 PowerShell，切換到你想要放專案的位置，然後啟動 Claude Code：

```powershell
cd D:\
claude
```

### 【步驟 2】請 Claude Code 建立專案

在 Claude Code 的對話框裡輸入：

```
幫我在 D 槽建立一個專案資料夾叫做「lobster-profile-generator」，
裡面建立以下檔案結構：

lobster-profile-generator/
├── index.html      （先放空白的 HTML5 基本結構）
├── style.css       （先放空白）
├── script.js       （先放空白）
└── README.md       （寫一段簡短說明：龍蝦 AI 個人檔案產生器）

然後幫我初始化 Git。
```

Claude Code 會在幾秒內把整個結構建好，包括 Git 的初始化。你會看到它依序建立了每個檔案，最後執行 `git init`。

### 【步驟 3】確認結果

```
幫我列出 lobster-profile-generator 資料夾的所有檔案，確認結構正確
```

Claude Code 會列出檔案清單。確認四個檔案都在之後，我們就可以把接力棒交給 Antigravity 了。

### 【步驟 4】做第一次 Commit

```
幫我把目前的狀態 commit 起來，訊息寫「初始化專案結構」
```

> 💡 **為什麼現在就要 commit？** 因為接下來 Antigravity 會大幅修改這些檔案。如果改壞了，我們可以用 Git 回到這個「乾淨」的起點。養成「做完一個階段就 commit 一次」的習慣，是很好的工作方式。

## 4.3 步驟二：用 Antigravity 製作網頁介面

---

骨架搭好了，現在讓 Antigravity 來做最擅長的事——打造一個漂亮的互動式網頁。

### 【步驟 1】在 Antigravity 中開啟專案

打開瀏覽器，進入 Antigravity（`https://idx.google.com/`）。你可以建立一個新的工作區，或是匯入你剛才用 Claude Code 建好的資料夾。

如果你用的是雲端版的 Antigravity，最簡單的方式是建立一個新的 Blank 工作區，然後把我們的需求直接告訴 AI，讓它從頭建立。

### 【步驟 2】用中文描述需求

在 AI 面板（`Ctrl+Shift+A`）中輸入以下內容：

```
請幫我建立一個「龍蝦 AI 個人檔案產生器」網頁，規格如下：

【頁面設計】
- 標題：🦞 龍蝦 AI 個人檔案產生器
- 副標題：為你的 OpenClaw 龍蝦打造獨一無二的個性
- 配色：深藍色漸層背景（#1a1a2e → #16213e），白色文字，橘紅色（#e94560）按鈕
- 風格：圓角卡片、有質感的陰影、現代簡潔

【表單欄位】
1. 龍蝦名字（文字輸入框，預設值：小龍）
2. 說話風格（下拉選單：溫柔體貼 / 幽默風趣 / 專業嚴謹 / 活潑可愛）
3. 主要語言（下拉選單：繁體中文 / 英文 / 日文）
4. 個性描述（多行文字框，placeholder：描述你希望龍蝦有什麼樣的個性...）
5. 擅長領域（多選框：生活助手 / 程式開發 / 教育教學 / 創意寫作 / 資料分析）
6. 回覆長度偏好（單選：簡短精要 / 中等長度 / 詳細完整）

【功能】
- 按下「🦞 產生個人檔案」按鈕後，根據表單內容生成 IDENTITY.md 格式的文字
- 生成結果顯示在下方的深色程式碼區塊中
- 有一個「📋 複製到剪貼簿」按鈕，一鍵複製生成的內容
- 複製成功後按鈕文字變成「✅ 已複製！」持續兩秒再恢復

【IDENTITY.md 的生成格式】
生成的內容要像這樣：

# IDENTITY.md

## 基本資訊
- 名字：{使用者輸入的名字}
- 語言：{使用者選的語言}

## 個性與風格
{使用者輸入的個性描述}

說話風格：{使用者選的風格}
回覆長度：{使用者選的長度}

## 擅長領域
{列出使用者勾選的領域}

## 行為規範
- 永遠保持友善和耐心
- 如果不確定答案，誠實告知
- 保護使用者的隱私資料

請建立 index.html、style.css、script.js 三個檔案。
```

### 【步驟 3】等待 AI 完成

按 Enter 送出之後，Antigravity 的 AI 會開始工作。你可以在旁邊觀看整個過程——它會分析需求、建立檔案、撰寫 HTML 結構、設計 CSS 樣式、編寫 JavaScript 互動邏輯。整個過程大約需要一到兩分鐘。

### 【步驟 4】預覽效果

AI 完成之後，使用 Antigravity 的內建瀏覽器預覽成果。你應該會看到一個深藍色背景、帶有表單的網頁。試試填寫表單，然後按下「產生個人檔案」按鈕，看看生成的 IDENTITY.md 內容是否正確。

![龍蝦個人檔案產生器網頁成果](../截圖/ch4_generator_preview.png)

### 【步驟 5】微調和修正

第一次生成的結果可能不完美——也許配色不夠好看、也許排版有點歪、也許生成的 IDENTITY.md 格式不太對。沒關係，直接在 AI 面板裡用中文告訴它要怎麼改：

```
請做以下調整：
1. 表單卡片的寬度改成最大 600px，置中顯示
2. 按鈕加上 hover 效果（滑鼠移上去時顏色變深）
3. 程式碼區塊用等寬字體，加上行號
4. 手機版也要能正常顯示（響應式設計）
```

多修改幾次，直到你滿意為止。

## 4.4 步驟三：用 Claude Code 微調設定檔格式

---

Antigravity 幫我們建好了網頁，但產生出來的 IDENTITY.md 格式可能需要微調。這種細節調整的工作，最適合交給 Claude Code 來做——它對文字格式的掌控力非常強。

### 【步驟 1】回到 Claude Code

切換回 PowerShell 的 Claude Code，進入專案資料夾：

```
幫我切換到 lobster-profile-generator 資料夾
```

### 【步驟 2】檢查 JavaScript 中的生成邏輯

```
幫我讀一下 script.js 裡面生成 IDENTITY.md 的那段程式碼
```

Claude Code 會把相關的程式碼片段找出來給你看。

### 【步驟 3】調整生成格式

如果你覺得生成的 IDENTITY.md 格式需要修改，直接告訴 Claude Code：

```
幫我修改 script.js 裡面的 IDENTITY.md 生成格式，改成這樣：

# IDENTITY.md - {龍蝦名字}的設定檔

_這是你的龍蝦 AI 的身分設定。請把這個檔案放到 OpenClaw 的 workspace 資料夾中。_

## 你是誰

你的名字叫做「{名字}」。{個性描述}

## 說話方式

- 風格：{說話風格}
- 語言：{主要語言}
- 回覆長度：{回覆長度偏好}

## 你擅長什麼

{列出擅長領域，每個領域一行，前面加 - }

## 基本規範

- 永遠保持友善和耐心
- 不確定的事情要誠實說「我不確定」
- 保護使用者的隱私，不洩露個人資料
- 用{主要語言}回覆，除非使用者用其他語言

---
_由龍蝦 AI 個人檔案產生器自動生成_
```

Claude Code 會精準地修改 JavaScript 程式碼中的字串模板，確保生成的格式符合你的要求。

### 【步驟 4】確認修改

```
修改完之後，幫我讀一下 script.js 確認改好了
```

## 4.7 回顧：三強協作的工作模式

---

讓我們暫停一下，回頭看看我們剛才做了什麼——以及兩個 AI 工具是怎麼分工合作的。

```
Claude Code                    Antigravity
    │                              │
    ├─ 建立資料夾結構              │
    ├─ 初始化 Git                  │
    ├─ 第一次 commit               │
    │                              │
    │     ──── 交棒給 Antigravity ────→
    │                              │
    │                              ├─ 製作網頁介面
    │                              ├─ 設計樣式和互動
    │                              ├─ 預覽和調整
    │                              │
    │     ←── 交棒回 Claude Code ────
    │                              │
    ├─ 微調設定檔格式              │
    ├─ 第二次 commit               │
    ├─ 儲存產出的 IDENTITY.md      │
    │                              │
    ▼                              ▼
  完成！
```

你有沒有注意到？整個過程中，你幾乎不需要自己寫任何程式碼。你做的事情是：**用中文描述需求，然後讓 AI 去執行**。這就是「三強聯手」的工作模式。

而 OpenClaw（龍蝦）在這個階段還沒有正式登場。它是最終的「受益者」——你用 Antigravity 和 Claude Code 做出來的設定檔，最後會用在龍蝦身上。等龍蝦安裝好之後，它會反過來成為你日常生活中最常使用的 AI 工具，而 Antigravity 和 Claude Code 則退居幕後，在你需要除錯、修改設定、開發新功能的時候才出場。

三個工具，各自在不同的時機扮演不同的角色。這就是「三強」的意義。

## 4.8 延伸挑戰（選做）

---

如果你覺得上面的練習還不夠過癮，這裡有幾個延伸挑戰。它們不是必做的，但如果你有時間，做完會讓你對 AI 工具的使用更加熟練。

### 挑戰一：加入更多欄位

在 Antigravity 裡，用中文告訴 AI 加入新的表單欄位，例如：

- 龍蝦的「禁忌話題」（不希望它聊的東西）
- 龍蝦的「口頭禪」
- 龍蝦的「打招呼方式」

### 挑戰二：加入深色 / 淺色主題切換

請 Antigravity 加入一個切換按鈕，讓使用者可以在深色主題和淺色主題之間切換。這是一個很好的 CSS 練習。

### 挑戰三：匯出為 JSON 格式

除了 IDENTITY.md 之外，也產生一份 JSON 格式的設定檔。JSON 是 OpenClaw 的 `openclaw.json` 設定檔使用的格式，提前熟悉它會有幫助。

### 挑戰四：部署到網路上

如果你有 GitHub 帳號，可以試著用 Claude Code 把專案推送到 GitHub，然後用 GitHub Pages 部署成一個可以公開存取的網頁。這樣你就可以把網址分享給朋友，讓他們也能產生自己的龍蝦設定檔。

> 💡 **不會做也沒關係**。這些都是選做的延伸挑戰，主要是給想多練習的人。如果你想直接進入 CH5 安裝龍蝦，完全沒問題。

## 4.9 常見問題

---

**問題 1：Antigravity 和 Claude Code 能同時存取同一個資料夾嗎？**

如果你的 Antigravity 是雲端版（在瀏覽器裡跑的），它有自己的工作區，跟你本機的資料夾是分開的。在這種情況下，你需要手動在兩邊同步檔案（例如用複製貼上的方式）。如果你的 Antigravity 和 Claude Code 都在本機操作同一個資料夾，那就可以無縫銜接。

**問題 2：我用 Antigravity 做的網頁，Claude Code 看得到嗎？**

如果它們操作的是同一個本機資料夾，是的。Claude Code 可以讀取和修改 Antigravity 建立的所有檔案。反之亦然。

**問題 3：Git commit 了之後，Antigravity 再修改會有衝突嗎？**

不會。Git 只在你手動執行 commit 的時候才會記錄。Antigravity 修改檔案跟 Git 沒有直接關係，你可以在 Antigravity 改完之後再用 Claude Code 做 commit。

**問題 4：產生的 IDENTITY.md 真的能用在龍蝦上嗎？**

可以，但只是「基本版」。在 CH8 我們會深入介紹 IDENTITY.md 的完整格式和進階設定。不過用我們這個產生器做出來的基本版，絕對能讓龍蝦正常運作。
