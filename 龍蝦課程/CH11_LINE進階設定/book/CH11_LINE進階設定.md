# CH11 | LINE 進階設定

---

在 CH6 你學會了用 LINE 跟龍蝦聊天——傳文字、傳語音、傳檔案，龍蝦都能好好回覆你。但如果你仔細看其他人的 LINE Bot（像是銀行的客服 Bot、餐廳的訂位 Bot），你會發現它們的聊天室下方有一排漂亮的選單按鈕，點一下就能執行功能；它們還會主動推送訊息給你，告訴你最新消息。

這些都是 LINE 的進階功能。你的龍蝦 Bot 也能做到——只是你還沒設定而已。

這一章會教你把這些功能一一開起來，讓你的 LINE Bot 從一個「能聊天」的助手，變成一個「好用又好看」的專業 Bot。

> **本章學習目標**
>
> 1. 設定 Rich Menu（圖文選單），讓龍蝦有漂亮的操作介面
> 2. 學會用推播訊息主動發送通知
> 3. 把龍蝦拉進 LINE 群組，變成群組助手
> 4. 認識 Flex Message 和 Quick Reply 等 LINE 特有功能

---

## 11.1 Rich Menu——圖文選單

### 11.1.1 什麼是 Rich Menu

Rich Menu 是 LINE Bot 聊天室底部的一塊可點擊的圖片區域。你在跟銀行、保險公司、餐廳的官方帳號聊天時，應該常看到它——下方有一排彩色的按鈕，像「查餘額」「轉帳」「客服」之類的。

點一下按鈕，Bot 就會收到對應的指令。這比叫使用者自己打字方便太多了——很多人根本不知道可以跟 Bot 說什麼，有了 Rich Menu，他們只要看到按鈕就知道能做什麼。

### 11.1.2 設計你的 Rich Menu 圖片

Rich Menu 的核心是一張圖片。LINE 規定了幾種尺寸：

| 尺寸類型 | 寬 × 高（像素） | 按鈕數量 | 建議使用場景 |
|---------|----------------|---------|------------|
| 大型 | 2500 × 1686 | 最多 6 個 | 功能較多的 Bot |
| 大型（矮版） | 2500 × 843 | 最多 3 個 | 簡潔版，不擋聊天畫面 |
| 小型 | 800 × 270 | 1-2 個 | 極簡風格 |

**設計圖片的方式：**

1. **用 Canva（推薦新手）**——到 https://www.canva.com，搜尋「LINE Rich Menu」模板，直接修改文字和顏色，下載 PNG 檔
2. **用 PowerPoint / Google Slides**——設定投影片尺寸為 2500×1686 像素，自己排版
3. **用 Antigravity**——在 CH2 學的 Google Antigravity，跟它說「幫我設計一個 LINE Rich Menu，2500×1686 像素，分成六格」
4. **用 Claude Code**——請 Claude Code 生成一個 HTML 版面，截圖後裁切

圖片上每一格就是一個「按鈕」，使用者點到哪一格，Bot 就收到哪一格對應的文字訊息。

**設計範例（六格版）：**

```
┌──────────┬──────────┬──────────┐
│          │          │          │
│  📋 功能  │  🌤️ 天氣  │  📰 新聞  │
│   總覽    │   查詢    │   摘要   │
│          │          │          │
├──────────┼──────────┼──────────┤
│          │          │          │
│  🔄 翻譯  │  📷 自拍  │  ❓ 幫助  │
│   助手    │   功能    │          │
│          │          │          │
└──────────┴──────────┴──────────┘
```

### 11.1.3 在 LINE Official Account Manager 設定 Rich Menu

**【步驟 1】** 到 LINE Developers Console（https://developers.line.biz/），找到你的 Channel。

**【步驟 2】** 在 Messaging API 分頁，點選 **「LINE Official Account Manager」** 的連結。這會開啟另一個管理後台。

**【步驟 3】** 在左側選單找到 **「聊天室相關」→「圖文選單」**（或 Rich Menu）。

**【步驟 4】** 點 **「建立」**。

**【步驟 5】** 設定基本資訊：
- **標題**——管理用的名稱，使用者看不到（例如「龍蝦主選單 v1」）
- **使用期間**——設定選單的生效時間範圍。如果你想永久使用，開始日期設今天，結束日期設幾年後
- **選單列顯示文字**——聊天室底部會顯示的文字（例如「點我開啟選單」）
- **預設是否顯示**——建議選「顯示」，這樣使用者一進聊天室就能看到

**【步驟 6】** 選擇版型。LINE 提供幾種預設的分割方式（2 格、3 格、4 格、6 格等）。選一個跟你的圖片設計一致的。

**【步驟 7】** 上傳你設計好的圖片。

**【步驟 8】** 設定每一格的動作。每格可以選擇：
- **傳送文字**——使用者點一下，就像他自己打字傳了那段文字。龍蝦會收到這段文字並回覆
- **開啟網址**——點一下會開啟指定的網頁
- **無動作**——純裝飾用

**最常用的是「傳送文字」。** 例如：

| 格子 | 傳送的文字 | 龍蝦收到後會做什麼 |
|------|-----------|-----------------|
| 功能總覽 | `你能幫我做什麼？` | 列出所有功能 |
| 天氣查詢 | `今天天氣如何？` | 回覆天氣資訊 |
| 新聞摘要 | `幫我看看今天有什麼新聞` | 回覆新聞摘要 |
| 翻譯助手 | `切換到翻譯模式` | 進入翻譯模式 |
| 自拍功能 | `幫我拍一張照片` | 觸發 Clawra 自拍 |
| 幫助 | `使用說明` | 回覆使用教學 |

**【步驟 9】** 按 **「儲存」**。

**【步驟 10】** 回到 LINE 聊天室，你會看到底部出現了 Rich Menu！點點看每個格子，確認龍蝦有正確回應。

> 💡 **小提醒**：Rich Menu 的設定變更可能需要幾分鐘才會在 LINE App 上更新。如果設好了卻看不到，先等一下，或試著關閉聊天室再重新打開。

### 11.1.4 Rich Menu 設計建議

- **文字要大**——手機螢幕不大，按鈕上的字要夠大才看得清楚
- **顏色要對比**——背景深色配淺色文字，或反過來。不要用太相近的顏色
- **圖示輔助**——每個按鈕加個小圖示（Emoji 就行），讓使用者一眼看出功能
- **不要放太多格子**——6 格已經很多了，如果功能不多，用 3 格就好
- **傳送的文字要自然**——龍蝦收到的是「文字訊息」，所以用自然語言效果最好。「今天天氣如何？」比「/weather」好

## 11.2 推播訊息

### 11.2.1 什麼是推播

在 CH6 的對話教學裡，都是使用者先傳訊息，龍蝦才回覆——這叫「被動回覆」。推播（Push Message）是反過來：**龍蝦主動傳訊息給你**，即使你沒有先說話。

推播的應用場景很多：

- 每天早上傳天氣預報
- 提醒你今天有行程
- 通知你有新的重要 Email
- 定時傳送每日金句或新聞摘要

### 11.2.2 推播的限制

LINE 的推播訊息有一些限制要知道：

| 方案 | 每月免費推播則數 | 超過後 |
|------|----------------|--------|
| 免費方案 | 200 則 | 無法再推播，下個月重置 |
| 輕用量方案 | 5,000 則 | 可加購 |
| 中用量方案 | 25,000 則 | 可加購 |

> ⚠️ **注意**：這裡的「則數」是指推播的「訊息數 × 接收人數」。如果你推播一則訊息給 10 個人，就算 10 則。免費方案的 200 則其實不多，如果只有你自己用，每天推一則大約夠用 6 天左右。

### 11.2.3 龍蝦怎麼推播

龍蝦的推播主要透過 **HEARTBEAT.md**（心跳排程）來實現。你在 HEARTBEAT.md 裡設定「每天早上 8 點傳天氣」，龍蝦就會在那個時間主動傳訊息給你。

這是 CH21 會深入教的內容，這裡先給你一個簡單的範例讓你知道推播長什麼樣子：

**範例：每天早上傳天氣**

在 `~/.openclaw/workspace/HEARTBEAT.md` 裡加上：

```markdown
## 每日任務

- 每天早上 08:00，查詢台北天氣，用簡短的一段話告訴我今天的天氣和穿衣建議
```

龍蝦就會在每天早上 8 點主動傳一則像這樣的訊息給你：

```
🌤️ 早安！今天台北 26°C，多雲偶陣雨。
下午有 60% 機率下雨，建議帶把傘出門。
穿薄長袖就好，不用外套。
```

### 11.2.4 用 CLI 手動推播

除了排程推播，你也可以透過龍蝦的技能或直接跟龍蝦說，讓它立刻推一則訊息給某人：

```
你（在 LINE 上）：幫我傳一則訊息給所有已配對的使用者，內容是「今天下午三點開會，不要遲到」
```

龍蝦會確認後執行推播。

> 💡 **小提醒**：推播訊息會消耗免費額度。日常使用以被動回覆為主，推播留給真正重要的通知。

## 11.3 群組應用

### 11.3.1 把龍蝦拉進 LINE 群組

龍蝦不只能在一對一的聊天室裡用——你也可以把它拉進 LINE 群組，讓它變成群組裡的 AI 助手。

**【步驟 1】** 先確認你的 Bot 允許被加入群組。到 LINE Developers Console → 你的 Channel → **Messaging API** 分頁：
- 找到 **「Allow bot to join group chats」**（允許 Bot 加入群組）
- 確認是 **Enabled**

**【步驟 2】** 在 LINE 群組裡，像加一般好友一樣邀請你的 Bot 加入。可以用 Bot 的 QR Code 或 LINE ID。

**【步驟 3】** Bot 加入群組後，預設的行為取決於你的 AGENTS.md 設定（CH10 有教）。

### 11.3.2 群組裡的龍蝦行為

在群組裡，龍蝦面對的情況跟一對一很不同：

- **訊息量大**——群組裡大家都在聊天，龍蝦不能每則都回
- **不是每則都跟龍蝦有關**——大部分訊息是群友之間的對話
- **隱私更敏感**——龍蝦知道的私人資訊不能在群組裡說出來

所以龍蝦在群組裡需要更「安靜」——只在被需要的時候才回話。

**龍蝦預設的群組行為：**

| 情況 | 龍蝦會回覆嗎 |
|------|------------|
| 有人在訊息裡 @龍蝦（如果 Bot 名稱被提及） | ✅ 會 |
| 有人直接問龍蝦問題 | ✅ 會 |
| 能提供有價值的資訊（翻譯、查資料） | ✅ 會 |
| 群友之間的閒聊 | ❌ 不會 |
| 已經有人回答了的問題 | ❌ 不會 |
| 只是想說「嗯」「好」的情況 | ❌ 不會 |

如果你想調整龍蝦在群組裡的行為（更活躍或更安靜），回到 CH10 的 AGENTS.md 群組規則部分修改。

### 11.3.3 群組應用場景

**場景一：讀書會小幫手**

把龍蝦拉進讀書會群組，大家可以：
- 問龍蝦書裡的概念
- 請龍蝦整理討論重點
- 請龍蝦翻譯英文段落

**場景二：家庭群組助手**

把龍蝦拉進家庭群組：
- 幫忙查餐廳、查路線
- 翻譯長輩看不懂的英文
- 回答小朋友的十萬個為什麼

**場景三：工作團隊助手**

把龍蝦拉進同事群組：
- 整理會議記錄
- 查技術問題
- 翻譯外國客戶的來信

### 11.3.4 群組使用的注意事項

1. **配對問題**——群組裡的每個成員如果想「私下」跟龍蝦聊天，還是需要各自完成配對。但在群組裡跟龍蝦互動不需要配對
2. **隱私很重要**——龍蝦在群組裡回覆時，所有群組成員都看得到。如果龍蝦知道你的私人資訊（因為 USER.md 或之前的私聊），它不應該在群組裡提起。預設的 AGENTS.md 已經有這個規則
3. **免費額度**——龍蝦在群組裡的回覆也會消耗 LINE 的免費訊息額度
4. **群組成員要知情**——把 AI Bot 加入群組前，最好先跟其他成員說一聲，避免有人不舒服

## 11.4 LINE 特有功能活用

LINE 除了基本的文字訊息，還有一些特別的訊息格式，可以讓龍蝦的回覆更豐富、互動更方便。

### 11.4.1 Flex Message——漂亮的卡片訊息

Flex Message 是 LINE 獨有的功能——它讓 Bot 可以發送「卡片式」的訊息，有標題、圖片、按鈕、分隔線，排版像一張小型網頁。

你在跟購物網站、旅遊平台的 LINE Bot 互動時，收到的那些漂亮的「商品卡片」「訂單確認」「行程表」，就是 Flex Message。

**Flex Message 長什麼樣子：**

想像一張卡片，上面有：
- 一張圖片（例如天氣圖示）
- 一個標題（「今日天氣預報」）
- 幾行內容（溫度、降雨機率、紫外線指數）
- 一個按鈕（「查看詳細預報」）

比純文字好看得多，資訊也更有條理。

**怎麼讓龍蝦發送 Flex Message：**

龍蝦的某些技能（Skills）會自動使用 Flex Message 來呈現結果。例如天氣技能可能會用卡片格式顯示天氣資訊，新聞技能可能會用卡片列出新聞標題。

你也可以直接跟龍蝦說：

```
幫我把以下資訊做成一張漂亮的卡片發給我：
標題：週末露營清單
內容：
- 帳篷
- 睡袋
- 卡式爐
- 食材
```

如果龍蝦安裝了支援 Flex Message 的技能，它就能生成漂亮的卡片回覆。

### 11.4.2 Quick Reply——快速回覆按鈕

Quick Reply 是出現在訊息下方的一排小按鈕。跟 Rich Menu 不同的是，Quick Reply 是**跟著特定訊息出現的**——龍蝦回覆一段話的同時，可以附帶幾個快速按鈕讓你選。

**範例情境：**

```
龍蝦：你想吃什麼類型的餐廳？

[ 中式 ]  [ 日式 ]  [ 義式 ]  [ 隨便 ]
```

你只要點一下按鈕就好，不用自己打字。這在選擇題的情境特別好用。

**Quick Reply 的特性：**

- 使用者點了其中一個按鈕後，所有按鈕就會消失
- 每則訊息最多 13 個按鈕
- 按鈕上的文字有長度限制（最多 20 個字元）
- 按鈕可以執行：傳文字、開網址、選日期、選位置等

**怎麼讓龍蝦使用 Quick Reply：**

龍蝦的某些技能會在適當的時候自動使用 Quick Reply。例如你跟龍蝦說「幫我訂晚餐」，它可能會用 Quick Reply 問你「幾點？」並附上時間按鈕。

你也可以在 IDENTITY.md 或技能設定裡指示龍蝦：

```markdown
## 互動方式

- 當需要使用者做選擇時，盡量使用 Quick Reply 按鈕，
  而不是叫使用者打字選擇
```

### 11.4.3 貼圖（Sticker）

龍蝦也能回覆 LINE 貼圖。雖然龍蝦不能買付費貼圖，但它可以使用 LINE 內建的免費貼圖。

在對話中偶爾搭配一個貼圖，會讓龍蝦的回覆更有溫度。你可以在 IDENTITY.md 裡加上：

```markdown
## 貼圖使用

- 開心的時候可以配一個笑臉貼圖
- 不要太頻繁，大約每 5-10 則訊息配一個就好
- 用來增加親切感，不是每則都需要
```

### 11.4.4 圖片輪播（Image Carousel）

當龍蝦需要展示多張圖片時（例如推薦餐廳、展示商品、分享今日新聞），可以使用圖片輪播——使用者左右滑動就能瀏覽多張卡片。

這通常由特定技能自動實現，你不需要手動設定。知道有這個功能就好，等你在 CH15 安裝更多技能後，自然會看到它。

## 11.5 常見問題

**Q1：Rich Menu 設好了但看不到**

幾個可能的原因：
- 設定還沒生效——等幾分鐘，或關閉 LINE 再重新打開
- 使用期間設定錯誤——確認開始日期是今天或更早
- 「預設是否顯示」設成了「不顯示」——去改成「顯示」
- 你用的是 LINE Developers Console，不是 LINE Official Account Manager——Rich Menu 要在 Official Account Manager 裡設定

**Q2：推播訊息的免費額度用完了怎麼辦**

免費方案每月 200 則用完就要等下個月重置。如果你需要更多，可以考慮升級到輕用量方案。在 LINE Official Account Manager 裡的「設定」→「方案」可以變更。不過對個人使用者來說，200 則通常夠用——關鍵是控制推播頻率和接收人數。

**Q3：龍蝦在群組裡都不回覆**

檢查幾件事：
- Bot 有沒有被允許加入群組（LINE Developers Console → Allow bot to join group chats → Enabled）
- 你有沒有 @龍蝦或直接叫它名字——在群組裡，龍蝦預設只回覆被提及的訊息
- AGENTS.md 裡的群組規則是不是設得太嚴格

**Q4：可以讓不同的人看到不同的 Rich Menu 嗎？**

可以，但需要透過 LINE Messaging API 的程式設定，不是在 Official Account Manager 裡做的。這是比較進階的功能，需要寫程式來指定「使用者 A 看 Rich Menu A，使用者 B 看 Rich Menu B」。對於進階用戶，OpenClaw 的技能系統可以幫你實現這個功能。

**Q5：Flex Message 和一般文字訊息有什麼差別？**

一般文字訊息就是純文字，頂多加個表情符號。Flex Message 是卡片式的排版，可以有圖片、標題、內容、按鈕，視覺上更豐富、資訊更有條理。缺點是製作比較複雜（需要 JSON 格式定義），但如果龍蝦的技能支援，它會自動幫你處理。

## 11.6 小結與展望

這一章讓你的 LINE Bot 脫胎換骨：

- **Rich Menu** 給了龍蝦一個專業的圖文選單，使用者一進聊天室就知道能做什麼
- **推播訊息** 讓龍蝦能主動通知你重要的事情
- **群組應用** 讓龍蝦從個人助手變成團隊助手
- **Flex Message 和 Quick Reply** 讓互動更豐富、更直覺

你的龍蝦現在在 LINE 上已經是一個相當完整的 Bot 了。但有一個問題你可能一直覺得很煩——每次電腦重開機、或 ngrok 重啟，你都得去 LINE Developers Console 更新 Webhook URL。這個問題在學習階段可以忍，但長期使用真的很不方便。

在下一章 CH12，我們要一勞永逸地解決這個問題——用 **Cloudflare Tunnel** 建立一個永久不變的正式域名。從此以後，不管你重啟幾次電腦，龍蝦的網址都不會改。
