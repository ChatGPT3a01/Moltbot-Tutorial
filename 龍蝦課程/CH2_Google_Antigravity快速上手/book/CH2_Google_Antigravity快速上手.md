# CH2 | Google Antigravity 快速上手

---

假設你今天想蓋一棟房子。在傳統的世界裡，你得自己畫設計圖、自己搬磚、自己釘釘子。就算你請了師傅幫忙，你還是得在旁邊盯著，一個步驟一個步驟地指揮。

但如果有這樣一種可能：你站在空地上，對著空氣說一句「我想要一棟兩層樓的白色小屋，有落地窗、有花園、有車庫」——然後一群工人自己跑過來，各自負責不同的部分，有的砌牆、有的裝窗、有的種花，最後你回來一看，房子已經蓋好了。

這就是 Google Antigravity 給你的感覺。

Antigravity 是 Google 在 2025 年底推出的 AI 開發環境。它長得像程式設計師常用的 VS Code 編輯器，但本質完全不同——在 Antigravity 裡，**AI 不是你的助手，而是你的施工隊**。你用中文描述你想要什麼，AI 會自己規劃步驟、自己寫程式碼、自己執行測試、自己打開瀏覽器確認結果。你要做的，只是「驗收」。

在上一章，我們已經確認了 Antigravity 可以用 Google 帳號登入。現在讓我們正式走進這個工具，學會它的基本操作。之後在安裝 OpenClaw 的時候，Antigravity 會成為你很好用的助手——沒錯，我們會用 AI 來幫我們安裝另一個 AI。

## 2.1 為什麼需要學 Antigravity

---

你可能會想：「這本書不是教龍蝦 AI 的嗎？為什麼要花一整章學另一個工具？」

這是一個好問題。讓我用一個實際的場景來回答。

假設你在 CH5 安裝 OpenClaw 的時候，安裝程式跑到一半出了錯——螢幕上跳出一堆紅色的英文字，你完全看不懂。這時候你該怎麼辦？

如果你會用 Antigravity，你只要把那堆錯誤訊息複製下來，貼給 Antigravity 的 AI，說一句：「這是什麼錯誤？幫我修好。」AI 就會分析問題、告訴你原因、甚至直接幫你修改設定檔。整個過程可能不到三十秒。

但如果你不會用 Antigravity（也不會用 Claude Code），你就只能把錯誤訊息拿去 Google 搜尋，然後在一堆英文的 Stack Overflow 討論串裡苦苦尋找答案——對零基礎的人來說，這可能會花上半小時到一小時。

這就是為什麼我們在安裝龍蝦之前，先教你 Antigravity 和 Claude Code。它們不只是獨立的工具，更是你後面整本書的**左右護法**——遇到問題找它們就對了。

而且 Antigravity 本身就是一個非常值得學習的 AI 工具。學會之後，你可以用它來快速製作網頁、建立小工具、產生報告，甚至開發屬於你自己的應用程式——全部用中文描述就好，不需要會寫任何程式碼。

## 2.2 Antigravity 是什麼

---

### 2.2.1 不只是編輯器，是 AI 工廠

讓我先釐清一個常見的誤解：Antigravity **不是** ChatGPT 的網頁版本加上一個編輯器。它的核心概念叫做 **Agent-First**——AI 代理程式是系統的核心，不是附加功能。

傳統的 AI 程式碼助手（像 GitHub Copilot）是這樣運作的：你寫程式碼，AI 在旁邊幫你補全。主導權在你手上，AI 只是「幫忙打字」。

Antigravity 的運作方式完全不同。你給 AI 一個任務（例如「幫我做一個記帳的網頁」），AI 會**自己規劃**需要哪些檔案、**自己建立**專案結構、**自己撰寫**程式碼、**自己打開**終端機執行指令、**自己啟動**瀏覽器確認效果——整個過程你可以在旁邊看，但不需要動手。

用比喻來說：傳統 AI 助手像是幫你扶著鑽頭的學徒，你指哪裡它鑽哪裡；Antigravity 像是一個完整的施工團隊，你只要告訴他們你要蓋什麼，他們自己搞定一切。

### 2.2.2 三大核心特色

Antigravity 有三個讓它與眾不同的特色：

**第一，Agent-First 架構。** AI 代理程式可以自主規劃任務、編輯程式碼、執行終端機指令、甚至操作瀏覽器。你不需要一步一步教它，它會自己想辦法。

**第二，多代理協作。** 這是 Antigravity 最強大的功能之一。你可以同時派出多個 AI 代理（Agent），讓它們各自處理不同的子任務。比如 Agent A 寫前端介面、Agent B 寫後端邏輯、Agent C 寫測試程式——三個 Agent 同時工作，互不干擾，開發速度瞬間翻好幾倍。

**第三，瀏覽器整合。** Agent 寫完程式碼之後，不只是把檔案存好就結束了。它會自動啟動開發伺服器、自動打開內建瀏覽器、自動檢查畫面是否正常。如果發現問題，它還會**自己回去修改程式碼**，然後再次確認——就像一個有責任感的工程師，交付之前一定先自己測試過。

### 2.2.3 跟其他工具比一比

如果你聽過 VS Code + Copilot 或 Cursor，可能會好奇它們跟 Antigravity 有什麼不同。下面這張表可以幫你一目了然：

| 項目 | VS Code + Copilot | Cursor | **Antigravity** |
|------|-------------------|--------|-----------------|
| AI 角色 | 輔助者（幫你補全） | 協作者（你問它答） | **執行者（自主完成）** |
| 程式碼補全 | ✅ | ✅ | ✅ |
| 自動執行終端機 | ❌ | 有限 | ✅ |
| 瀏覽器整合 | ❌ | ❌ | ✅ |
| 多 Agent 同時工作 | ❌ | ❌ | ✅ |
| 個人版費用 | US$10/月 | US$20/月 | **免費** |

簡單來說：Copilot 是幫你打字的助手，Cursor 是跟你討論的夥伴，**Antigravity 是直接幫你把事情做完的團隊**。而且它目前完全免費。

## 2.3 登入與建立工作區

---

認識了 Antigravity 的概念之後，讓我們實際動手操作。如果你在 CH1 已經確認可以用 Google 帳號登入，這裡會進展得很快。

### 【步驟 1】開啟 Antigravity

打開 Google Chrome 瀏覽器（建議用 Chrome，相容性最好），在網址列輸入：

```
https://idx.google.com/
```

用你的 Google 帳號登入。如果是第一次登入，會需要授權一些權限（讀取 Google Drive、管理專案等），點「允許」即可。

![Antigravity 登入後的首頁](../截圖/ch2_antigravity_home.png)

### 【步驟 2】建立新的工作區

登入之後，你會看到 Antigravity 的首頁。畫面上可能有一些範本（Template）可以選擇，像是「Blank」、「React」、「Next.js」等等。

我們先從最簡單的開始。點選 **Blank**（空白專案），系統會問你要替這個工作區取什麼名字。輸入一個好辨認的名稱，例如：

```
my-first-project
```

點「Create」之後，Antigravity 會花幾秒鐘的時間幫你建立工作區。建好之後，你會看到一個類似 VS Code 的編輯器介面。

> 💡 **什麼是工作區？** 你可以把工作區想像成一個「工作桌」。每個專案有自己的工作桌，上面放著屬於這個專案的所有檔案和工具。你可以同時擁有多個工作區，各自獨立，互不影響。

![建立新工作區](../截圖/ch2_create_workspace.png)

## 2.4 認識 Antigravity 的介面

---

工作區建好之後，你面前會是一個功能豐富的編輯器介面。乍看之下可能覺得按鈕很多、有點眼花，但其實整個介面可以簡單地分成四個區域。讓我帶你一一認識。

### 2.4.1 四大區域總覽

```
┌───────┬────────────────────────┬──────────────┐
│       │                        │              │
│ ① 側  │    ② 編輯區             │  ③ AI 面板   │
│ 邊    │   （寫程式碼的地方）      │ （跟AI對話）  │
│ 欄    │                        │              │
│       │                        │              │
│       ├────────────────────────┤              │
│       │    ④ 終端機面板          │              │
│       │   （執行指令的地方）      │              │
└───────┴────────────────────────┴──────────────┘
```

**① 側邊欄（Activity Bar）**

最左邊那一排圖示，就是側邊欄。你最常用到的是：

- **檔案總管**（快捷鍵 `Ctrl+Shift+E`）：瀏覽你專案裡的所有檔案和資料夾
- **搜尋**（`Ctrl+Shift+F`）：在整個專案中搜尋某段文字
- **版本控制**（`Ctrl+Shift+G`）：Git 操作（之後 CH3 會詳細介紹）

**② 編輯區（Editor）**

畫面正中央、佔最大面積的區域。這裡就是你看程式碼、寫程式碼的地方。上方有分頁標籤，可以同時打開多個檔案。左邊有行號，方便定位。程式碼會自動語法高亮——不同類型的文字用不同顏色顯示，讓你一眼就能分辨。

**③ AI 面板（最重要！）**

畫面右側的面板，這是 Antigravity 跟傳統編輯器最大的不同之處。你在這裡跟 AI 對話——輸入你的需求，AI 就會開始工作。它會在編輯區裡建立和修改檔案、在終端機裡執行指令、甚至自動打開瀏覽器預覽效果。

如果 AI 面板沒有出現，按 `Ctrl+Shift+A` 就能把它叫出來。

**④ 終端機面板（Terminal）**

畫面下方的黑色區域。終端機就是「命令列」，用來執行各種指令。你通常不需要自己在這裡輸入什麼——AI 會自動在這裡執行它需要的指令。但如果你想手動跑個指令（比如檢查 Node.js 版本），也可以直接在這裡輸入。

按 `` Ctrl+` ``（鍵盤左上角那個反引號鍵）可以開啟或關閉終端機面板。

![Antigravity 四大區域標示](../截圖/ch2_interface_overview.png)

### 2.4.2 常用快捷鍵

你不需要把所有快捷鍵都背起來，但以下幾個建議記住，會讓你的操作快很多：

| 功能 | 快捷鍵 | 什麼時候用 |
|------|--------|-----------|
| 開啟 AI 面板 | `Ctrl+Shift+A` | 想跟 AI 對話時 |
| 聚焦 AI 輸入框 | `Ctrl+L` | 快速跳到 AI 對話輸入框 |
| 命令面板 | `Ctrl+Shift+P` | 找不到某個功能時 |
| 快速開檔案 | `Ctrl+P` | 想打開某個檔案時 |
| 開啟終端機 | `` Ctrl+` `` | 想看或執行指令時 |
| 儲存檔案 | `Ctrl+S` | 修改完檔案後 |

> 💡 **小技巧**：如果你記不住快捷鍵，按 `Ctrl+Shift+P` 打開「命令面板」，然後用中文輸入你想做的事（例如「terminal」或「AI」），就能找到對應的功能。命令面板是你的萬用搜尋工具。

## 2.5 Editor View 實戰：做一個自我介紹網頁

---

認識了介面之後，讓我們來做一個真正的練習。我們要用 Antigravity 的 AI 來製作一個**個人自我介紹網頁**——你不需要寫任何一行程式碼，全部用中文交給 AI 就好。

### 【步驟 1】開啟 AI 面板

按 `Ctrl+Shift+A` 開啟右側的 AI 面板。你會看到一個輸入框，跟 ChatGPT 的對話框很像。

### 【步驟 2】用中文描述你的需求

在 AI 面板的輸入框裡，輸入以下內容（你可以根據自己的資料修改）：

```
請幫我建立一個個人自我介紹網頁，包含以下內容：
- 名字：王小明
- 職業：國小老師
- 興趣：攝影、旅行、做菜
- 一句話座右銘：「用 AI 讓教學更有趣」
- 設計風格：簡潔現代，藍白配色
- 要有一張佔位的大頭照區域
- 底部要有 Email 聯絡方式

請建立 index.html 和 style.css 兩個檔案。
```

按 Enter 送出。

### 【步驟 3】觀察 AI 的工作過程

接下來就是最神奇的部分了——你什麼都不需要做，只要在旁邊看。

AI 會開始自動工作。你可以在 AI 面板裡看到它的「思考過程」：它會先分析你的需求，規劃要建立哪些檔案，然後一個一個地建立並撰寫程式碼。同時，你會看到左邊的編輯區裡自動跳出新的檔案、程式碼一行一行地寫入。

整個過程可能需要 30 秒到 1 分鐘，取決於網路速度和 AI 模型的回應速度。

> 💡 **不要在 AI 工作的時候打斷它**。等它跑完整個流程（你會看到 AI 面板顯示完成的訊息），再來檢查結果。

### 【步驟 4】預覽成果

AI 完成之後，你的專案裡應該會多出 `index.html` 和 `style.css` 兩個檔案。現在讓我們看看成果。

在終端機面板裡，AI 可能已經自動幫你啟動了預覽伺服器。如果沒有，你可以自己在終端機裡輸入：

```bash
npx serve .
```

然後在 Antigravity 的內建瀏覽器（畫面右上角通常會有一個瀏覽器圖示）中打開預覽，你就能看到你的個人網頁了。

![AI 自動生成的個人網頁成果](../截圖/ch2_first_webpage.png)

### 【步驟 5】修改和調整

看到成果之後，你可能想改一些東西。比如你覺得字太小、配色不好看、或想加一段內容。你不需要自己去改程式碼——直接在 AI 面板裡用中文告訴它就好：

```
請把名字的字體放大到 36px，座右銘改成斜體，然後背景色改成淡灰色。
```

AI 就會自動找到需要修改的程式碼，幫你改好。

> 💡 **修改和重做的差別**：如果你只想微調，用「請把 XX 改成 YY」這樣的指令就好。但如果你覺得整個設計方向不對，想要重來，可以說「請重新設計這個頁面，這次用深色主題」。AI 會理解你的意圖。

恭喜你完成了第一個 Antigravity 專案！你剛才做的事情，傳統上需要至少會 HTML 和 CSS 的人花十幾分鐘才能完成。而你只用了幾句中文和不到兩分鐘。

## 2.6 Manager View：多 Agent 同時工作

---

剛才在 Editor View 裡，你和一個 AI Agent 一對一合作。這已經很強大了。但 Antigravity 還有一招殺手鐧：**Manager View**——讓你同時派出多個 Agent，各自處理不同的任務。

### 2.6.1 什麼時候需要多個 Agent

一對一合作適合比較簡單的任務，像是做一個網頁、改一段程式碼。但如果你的任務比較複雜，涉及多個不同的部分，一個 Agent 一個一個做就太慢了。這時候你可以一次派出好幾個 Agent：

| 情境 | 一個 Agent | 多個 Agent |
|------|-----------|-----------|
| 做一個簡單的網頁 | ✅ 足夠 | 不需要 |
| 同時做前端和後端 | 要排隊做 | ✅ Agent A 做前端、Agent B 做後端 |
| 同時建立三個不同的頁面 | 要一個一個做 | ✅ 三個 Agent 同時做三個頁面 |
| 一邊寫程式一邊寫測試 | 做完程式再寫測試 | ✅ 一個寫程式、一個寫測試 |

### 2.6.2 切換到 Manager View

在 Antigravity 的介面中，你會看到上方或側邊有兩個檢視模式的切換按鈕：

- **Editor View**（編輯器檢視）：剛才我們用的模式，適合一對一合作
- **Manager View**（管理員檢視）：可以同時管理多個 Agent

點擊 **Manager View** 切換過去。你會看到一個不同的介面——不再是編輯器，而是一個類似「任務看板」的畫面，每個 Agent 有自己的一張「卡片」。

![切換到 Manager View](../截圖/ch2_manager_view.png)

### 2.6.3 實戰：同時製作三個頁面

讓我們來試試多 Agent 的威力。假設你要做一個小型的個人網站，包含三個頁面：首頁、自我介紹頁、作品集頁。

在 Manager View 中，你可以建立三個 Agent，分別給他們不同的任務：

**Agent 1 的任務：**
```
請建立首頁 index.html，包含網站名稱、導航選單（首頁、關於我、作品集）、
一段歡迎語，和一張佔位的 Banner 圖片。使用藍白配色的現代風格。
```

**Agent 2 的任務：**
```
請建立關於我頁面 about.html，包含個人照片區、自我介紹文字、
學經歷時間軸、聯絡方式。風格要跟首頁一致（藍白配色）。
```

**Agent 3 的任務：**
```
請建立作品集頁面 portfolio.html，用卡片式排版展示六個作品，
每個作品有標題、簡介和佔位圖片。風格要跟首頁一致。
```

送出之後，你會看到三個 Agent 同時開始工作。它們各自在自己的「工作空間」裡建立檔案、撰寫程式碼，完全不會互相干擾。整個過程可能只需要一兩分鐘，但產出的是三個完整的網頁。

> 💡 **注意事項**：多個 Agent 同時工作時，如果它們需要修改同一個檔案（例如共用的 `style.css`），偶爾會產生衝突。建議在任務描述中明確指定每個 Agent 負責哪些檔案，減少重疊。

## 2.7 AI 模型的選擇

---

在 Antigravity 裡，你可以選擇不同的 AI 模型來驅動你的 Agent。每個模型有不同的特性：

| 模型 | 提供商 | 特色 | 費用 |
|------|--------|------|------|
| **Gemini 3 Pro** | Google | 預設模型，回應速度快，免費額度大方 | 免費 |
| **Claude Sonnet 4.5** | Anthropic | 程式碼品質特別好 | 需另設 API Key |
| **Claude Opus 4.5** | Anthropic | 最強推理能力 | 需另設 API Key |

對於新手來說，預設的 **Gemini 3 Pro** 就非常夠用了。它是 Google 自家的模型，在 Antigravity 裡有大方的免費額度，日常開發完全不用擔心費用。

如果你在 CH1 已經申請了 Anthropic 的 API Key，也可以在 Antigravity 的設定中加入，切換到 Claude 模型使用。Claude 在程式碼品質和邏輯推理上通常表現更好，但需要額外付費。

要切換模型，在 AI 面板的輸入框上方通常會有一個模型選擇的下拉選單。點一下就能切換。

> 💡 **建議策略**：平常用 Gemini 3 Pro（免費、快速），遇到特別複雜的任務再切換到 Claude Opus（最強、但較貴）。

到目前為止，你已經學會了用 Antigravity 做網頁。但它的能力遠不止於此。讓我列舉一些在這本書後續章節中，以及你日常生活裡，Antigravity 可以幫到你的場景：

**日常實用的應用：**

## 2.9 常見問題與疑難排解

---

使用 Antigravity 的過程中，你可能會遇到一些小問題。以下是新手最常碰到的狀況和解決方法：

**問題 1：AI 面板沒有出現**

按 `Ctrl+Shift+A`。如果還是沒有，試試按 `Ctrl+Shift+P` 打開命令面板，搜尋「AI」或「Agent」，應該能找到開啟的選項。

**問題 2：AI 回應速度很慢**

Gemini 3 Pro 有每日免費額度上限。如果你用了很多次，可能會被限速。解決方式是等待隔天額度重置，或是切換到其他 AI 模型。

**問題 3：AI 生成的網頁跑版了**

在 AI 面板裡告訴它問題所在，例如：「文字跑出了邊界」「圖片沒有置中」。AI 會自動修正。你也可以貼上截圖（Manager View 支援圖片輸入），讓 AI 看到實際的問題。

**問題 4：專案裡的檔案亂了**

在 AI 面板輸入：「請幫我整理目前的專案結構，刪除不需要的檔案。」AI 會幫你清理。

**問題 5：想回到之前的版本**

如果 AI 改壞了什麼東西，你可以按 `Ctrl+Z` 在編輯區裡逐步撤銷。如果改動太多回不去了，可以透過左側的版本控制面板（Git）來恢復之前的狀態——這個我們在 CH3 會詳細教。

## 2.10 小結與展望

---

在這一章裡，我們從零開始認識了 Google Antigravity。

首先，我們理解了 Antigravity 的核心概念——它不是一個幫你補全程式碼的助手，而是一個能**自主完成整個開發任務的 AI 團隊**。Agent-First 的架構、多代理協作、瀏覽器整合，這三大特色讓它在所有 AI 開發工具中獨樹一幟。

接著，我們實際登入了 Antigravity、認識了四大操作區域和常用快捷鍵。然後在 Editor View 中完成了第一個練習——用幾句中文就做出了一個個人自我介紹網頁。我們也體驗了 Manager View 的多 Agent 協作，同時派出三個 Agent 分別製作三個不同的頁面。

最重要的是，你現在已經知道了**如何用自然語言跟 AI 協作**。這個能力不只在 Antigravity 裡有用，在後面使用 Claude Code 和 OpenClaw 的時候同樣適用。「描述清楚你的需求」——這是跟所有 AI 工具打交道的第一法則。

在下一章（CH3），我們要認識第三位夥伴——**Claude Code**。如果說 Antigravity 是有圖形介面的 AI 工程師，Claude Code 就是住在終端機裡的 AI 特助。它沒有花俏的畫面，但做事又快又精準。特別是在檔案操作、Git 版本控制、和系統指令方面，Claude Code 的表現甚至優於 Antigravity。

兩個工具各有所長，學會了之後你就能隨時選擇最適合的那一個。讓我們繼續往前走吧。
