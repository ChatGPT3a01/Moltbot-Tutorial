# CH8 | 拍照與視覺辨識功能

---

前面兩章你學會了用 LINE 和 Telegram 跟龍蝦聊天。到目前為止，你們之間的互動主要是文字——你打字問問題，龍蝦打字回答。但你有沒有想過：如果你遇到一個不會描述的東西，比如路邊一種叫不出名字的花、菜單上看不懂的外文、或是電腦螢幕上一個奇怪的錯誤訊息——這些東西用文字很難說清楚，但用「拍一張照片」就能完美表達。

好消息是，龍蝦不只會讀文字，它還有一雙「眼睛」。你只要把照片傳給龍蝦，它就能看懂照片裡的內容，然後告訴你它看到了什麼。更酷的是，你還可以讓龍蝦反過來「自拍」——叫它拍一張照片回傳給你，而且可以指定穿搭、場景、動作。

這些功能在 LINE 和 Telegram 上**都能使用**，操作方式完全一樣。

> **本章學習目標**
>
> 1. 了解龍蝦的圖片辨識（Vision）能力，知道哪些模型支援
> 2. 實際傳照片給龍蝦，體驗各種辨識場景
> 3. 安裝 Clawra 自拍功能，讓龍蝦擁有虛擬外貌
> 4. 學會自拍功能的各種玩法和客製化方式

## 8.1 龍蝦看得懂照片——Vision 功能

### 8.1.1 什麼是 Vision

Vision（視覺辨識）是現代 AI 模型的一項內建能力。簡單來說，就是 AI 不只能讀文字，還能「看」圖片。你傳一張照片給龍蝦，AI 模型會分析圖片裡的內容——辨識物品、讀取文字、理解場景——然後用文字告訴你它看到了什麼。

這不是什麼需要額外安裝的東西。只要你使用的 AI 模型有支援 Vision 功能，龍蝦就天生看得懂圖片。目前主流的模型支援狀況：

| AI 模型 | 支援 Vision 嗎 | 備註 |
|---------|---------------|------|
| **Gemini 3 Flash** | ✅ 支援 | 免費、速度快，推薦 |
| **Gemini 3 Pro** | ✅ 支援 | 辨識更精準 |
| **GPT-5.2** | ✅ 支援 | 強大的圖片理解能力 |
| **Claude Sonnet 4.6** | ✅ 支援 | 文字提取特別強 |
| **Claude Opus 4.6** | ✅ 支援 | 最強的分析能力 |
| **Ollama — llama3.1** | ❌ 不支援 | 純文字模型 |
| **Ollama — llava** | ✅ 支援 | Ollama 上的視覺模型 |
| **Ollama — llama3.2-vision** | ✅ 支援 | 較新的視覺模型 |

> 💡 **如果你用 Ollama**：預設安裝的 `llama3.1` 是純文字模型，看不懂圖片。要使用 Vision 功能，需要另外下載一個視覺模型：
> ```powershell
> ollama pull llava
> ```
> 然後把龍蝦的模型切換過去：
> ```powershell
> openclaw config set agents.defaults.model.primary "llava"
> openclaw gateway restart
> ```

### 8.1.2 怎麼用——就是傳照片

使用方式簡單到不需要教：打開 LINE 或 Telegram，傳一張照片給龍蝦，然後附上你的問題。就這樣。

你可以先傳照片再打字，也可以照片和文字一起傳（LINE 和 Telegram 都支援圖片加說明文字）。如果你只傳照片不打字，龍蝦會自動描述它看到的內容。

## 8.2 Vision 實戰：10 種好用的辨識場景

光說不練沒有感覺，讓我們實際體驗一下。以下是十種你在日常生活中一定會用到的圖片辨識場景，每一種都附上具體的操作方式。

### 8.2.1 辨識物品

> 📷 *拍一張桌上的東西*
> 「這張照片裡有什麼？」

龍蝦會列出它看到的所有物品，通常描述得非常準確。甚至能辨認品牌、型號。

### 8.2.2 食材辨識 + 食譜建議

> 📷 *打開冰箱，拍一張裡面的食材*
> 「幫我看看冰箱裡有什麼，可以煮什麼菜？」

這是最實用的場景之一。龍蝦不只會列出食材，還能根據你手邊的東西推薦菜色，甚至給你詳細的作法。試試看加上一些條件：

```
幫我用這些食材做一道 20 分鐘內能完成的家常菜
```

### 8.2.3 錯誤訊息分析

> 📷 *截圖電腦上的錯誤訊息*
> 「這個錯誤是什麼意思？要怎麼解決？」

遇到電腦問題時特別好用。你不需要打一大段文字描述問題，直接截圖傳過去就好。龍蝦會讀取截圖中的文字，理解錯誤的原因，然後給你解決方法。

### 8.2.4 翻譯外文

> 📷 *拍一張外文菜單、路標、說明書*
> 「這上面寫什麼？幫我翻成中文」

出國旅遊時的神器。不管是日文菜單、韓文路標、法文說明書，拍個照傳給龍蝦就搞定了。比開翻譯 App 拍照還方便，因為龍蝦不只翻譯，還能解釋文化背景和使用建議。

### 8.2.5 文件摘要

> 📷 *拍一頁課本或文件*
> 「幫我整理這一頁的重點」

開會時拍下白板上的筆記、上課時拍下投影片、整理文件時拍下紙本資料——龍蝦都能幫你讀取內容然後做摘要。

### 8.2.6 植物 / 動物辨識

> 📷 *拍一朵花、一棵樹、一隻昆蟲*
> 「這是什麼？」

散步時看到不認識的植物或動物，拍張照問龍蝦。它通常能辨認出種類，還會告訴你一些有趣的小知識。

### 8.2.7 穿搭建議

> 📷 *拍你今天的穿搭*
> 「這樣穿去面試適合嗎？有什麼建議？」

龍蝦會分析你的穿搭，給出配色、場合適合度、改善建議等回饋。

### 8.2.8 數學題 / 作業協助

> 📷 *拍一道數學題*
> 「幫我解這一題，要有詳細過程」

學生福音。拍照傳給龍蝦，它會讀取題目然後一步步解題給你看。不過要注意——理解解題過程比直接抄答案重要得多。

### 8.2.9 商品比價

> 📷 *拍一個商品的包裝或標籤*
> 「這個產品大概多少錢？CP 值高嗎？」

在商店看到一個商品不確定值不值得買，拍個照問龍蝦。它能根據品牌、規格、成分等資訊給你建議。

### 8.2.10 圖表分析

> 📷 *傳一張圖表（長條圖、折線圖、圓餅圖等）*
> 「幫我解讀這張圖表的重點」

工作上常常需要看懂各種報表和圖表。把圖表傳給龍蝦，它能幫你分析趨勢、找出關鍵數據、甚至發現你沒注意到的異常。

## 8.3 圖片辨識的限制與注意事項

雖然龍蝦的視覺能力很強，但有幾個限制要知道：

### 8.3.1 照片品質很重要

模糊的照片、太暗的照片、角度太歪的照片，辨識準確度都會下降。拍的時候盡量：

- 對焦清楚
- 光線充足
- 目標物體佔畫面的主要位置
- 如果是文字，盡量正面拍攝（不要太斜）

### 8.3.2 隱私考量

如果你使用的是雲端 AI 模型（Gemini、GPT、Claude），傳出去的照片會被送到 AI 公司的伺服器進行處理。大部分公司都聲明不會用你的資料來訓練模型，但如果照片包含非常敏感的資訊（身分證、銀行帳單、醫療紀錄等），請三思再傳。

如果你非常在意隱私，可以使用 Ollama 的本地視覺模型（如 `llava`）——照片完全在你的電腦上處理，不會傳到任何外部伺服器。

### 8.3.3 不是百分之百準確

AI 的視覺辨識有時候會出錯，特別是：

- 小字體或手寫字（可能會辨識錯誤）
- 很相似的物品（比如分不清某些品種的花）
- 需要專業知識的內容（比如醫療影像、電路圖）

把龍蝦的辨識結果當作參考，重要的決策還是要交給專業人士。

## 8.4 龍蝦會自拍——認識 Clawra

前面講的是你傳照片給龍蝦看，現在要講一個更有趣的功能：**龍蝦主動拍照回傳給你**。

這個功能叫做 **Clawra**，它是 OpenClaw 社群開發的一個自拍技能。裝了 Clawra 之後，龍蝦就擁有了一個「虛擬外貌」——你可以叫它拍自拍、指定穿搭、指定場景，它會用 AI 繪圖技術生成一張符合描述的照片回傳給你。

而且這個功能在 **LINE 和 Telegram 上都能用**，你在哪個平台叫龍蝦自拍，它就在哪個平台回傳照片。

### 8.4.1 Clawra 是怎麼運作的

簡單來說，Clawra 的運作流程是：

1. 你在聊天室裡說「拍張自拍」
2. 龍蝦理解你的請求，提取你描述的穿搭、場景、動作等關鍵字
3. 龍蝦把這些資訊送給 AI 繪圖服務（fal.ai），搭配一張預設的角色參考圖
4. AI 繪圖服務生成一張符合描述的照片
5. 龍蝦把照片回傳到你的聊天室

整個過程通常在 5-10 秒內完成。

## 8.5 安裝 Clawra

### 8.5.1 申請 fal.ai API Key

Clawra 使用 fal.ai 的 AI 繪圖服務來生成照片。在安裝之前，你需要先申請一個 fal.ai 的 API Key。

**【步驟 1】** 打開瀏覽器，前往 fal.ai 的 API Key 管理頁面：

```
https://fal.ai/dashboard/keys
```

**【步驟 2】** 如果你還沒有 fal.ai 帳號，點擊註冊。可以用 **Google 帳號**或 **GitHub 帳號**一鍵登入，非常方便。

**【步驟 3】** 登入後，你會看到 API Keys 的管理頁面。點擊 **「Create」** 按鈕，產生一組新的 API Key。

![fal.ai API Key 頁面](../截圖/ch8_fal_api_key.png)

**【步驟 4】** 複製產生的 API Key，存到你的帳號清單裡。

> 💡 **fal.ai 有免費額度**，足夠你學習和日常使用。每個月會重置。如果你只是偶爾讓龍蝦自拍，免費額度綽綽有餘。

### 8.5.2 一鍵安裝 Clawra

**【步驟 5】** 打開 PowerShell（地端安裝）或終端機（Codespaces / Zeabur），執行：

```powershell
npx clawra@latest
```

安裝程式會自動幫你做以下事情：

1. **檢查 OpenClaw** 是否已安裝且正在運行
2. **要求你輸入 fal.ai API Key**——把剛才複製的 Key 貼上
3. **安裝 Clawra 技能**到 `~/.openclaw/skills/clawra-selfie/` 目錄
4. **修改 OpenClaw 設定檔**，啟用 Clawra 技能
5. **更新 SOUL.md**，讓龍蝦知道自己「有身體、可以自拍」

整個安裝過程大約 1-2 分鐘。

**【步驟 6】** 安裝完成後，重啟龍蝦：

```powershell
openclaw gateway restart
```

### 8.5.3 如果一鍵安裝失敗

`npx clawra@latest` 偶爾可能會因為網路或環境問題失敗。如果遇到這種情況，可以用手動方式安裝：

**手動步驟 1：下載 Clawra 技能**

```powershell
git clone https://github.com/SumeLabs/clawra $env:USERPROFILE\.openclaw\skills\clawra-selfie
```

**手動步驟 2：修改 OpenClaw 設定檔**

```powershell
notepad $env:USERPROFILE\.openclaw\openclaw.json
```

找到 `"skills"` 區塊（如果沒有就新增），在 `"entries"` 裡加入：

```json
"clawra-selfie": {
  "enabled": true,
  "env": {
    "FAL_KEY": "你的fal.ai API Key"
  }
}
```

**手動步驟 3：更新 SOUL.md**

```powershell
notepad $env:USERPROFILE\.openclaw\workspace\SOUL.md
```

在檔案最後加入以下內容：

```markdown
## Clawra Selfie Capability

你有自拍的能力。當使用者要你拍照或自拍時，使用 clawra-selfie 技能生成照片。
你有實體外貌，可以出現在各種場景中。
不要說「我沒有身體」或「我無法拍照」，你可以的。
```

**手動步驟 4：重啟 Gateway**

```powershell
openclaw gateway restart
```

## 8.7 自拍功能玩法大全

Clawra 不只是簡單的「拍一張照片」。它能根據你的描述，生成各種不同場景、穿搭、表情的照片。你說得越具體，生成的照片就越貼近你的想像。

### 8.7.1 基本自拍

最簡單的用法，直接叫龍蝦拍照：

| 你說的話 | 龍蝦會做什麼 |
|---------|------------|
| 拍張自拍 | 生成一張基本的自拍照 |
| 自拍一張給我 | 同上 |
| 讓我看看你 | 生成自拍照回傳 |
| Send me a selfie | 英文也通 |

### 8.7.2 指定穿搭和造型

| 你說的話 | 龍蝦會拍 |
|---------|--------|
| 穿牛仔外套自拍一張 | 穿牛仔外套的全身照 |
| 戴墨鏡拍一張帥的 | 戴墨鏡的酷照 |
| 穿西裝打領帶 | 正式穿搭照 |
| 穿運動服拍一張 | 運動風格照 |

當你描述穿搭或造型時，Clawra 會自動切換到 **Mirror 模式**（鏡像模式），生成全身照來展示整體造型。就像你站在全身鏡前面自拍一樣。

### 8.7.3 指定場景和地點

| 你說的話 | 龍蝦會拍 |
|---------|--------|
| 在咖啡廳拍一張 | 咖啡廳場景的照片 |
| 在海邊自拍 | 海灘場景照 |
| 在東京街頭拍一張 | 東京街景背景照 |
| 在辦公室拍一張 | 辦公室場景照 |

描述場景或地點時，Clawra 會切換到 **Direct 模式**（直拍模式），生成特寫或半身照，重點放在場景氛圍。就像別人幫你在景點前面拍照一樣。

### 8.7.4 指定表情和動作

| 你說的話 | 龍蝦會拍 |
|---------|--------|
| 笑一個！ | 微笑特寫 |
| 拍一張酷酷的 | 酷表情照片 |
| 比個讚拍一張 | 比讚的照片 |
| 正在寫程式的照片 | 電腦前工作照 |

### 8.7.5 組合技——穿搭 + 場景 + 動作

你可以把穿搭、場景、動作任意組合，讓描述更豐富：

| 你說的話 | 龍蝦會拍 |
|---------|--------|
| 穿白色洋裝在花園裡拍一張 | 白洋裝 + 花園場景 |
| 戴棒球帽在球場比讚 | 棒球帽 + 球場 + 比讚動作 |
| 穿西裝在會議室拍一張專業照 | 西裝 + 會議室 + 專業風 |
| 穿雨衣撐傘在雨天街頭 | 雨衣 + 雨天街景 |

> 💡 **你不需要手動選擇拍照模式**。龍蝦會自動判斷你的描述偏向穿搭（Mirror 模式）還是場景（Direct 模式），然後選擇最合適的方式來生成照片。

### 8.7.6 兩種拍照模式解析

| 模式 | 什麼時候觸發 | 效果 | 觸發關鍵字 |
|------|------------|------|-----------|
| **Mirror（鏡像模式）** | 描述穿搭、造型時 | 全身照，重點在衣服和整體造型 | 穿、戴、outfit、wearing、fashion |
| **Direct（直拍模式）** | 描述地點、表情時 | 特寫或半身照，重點在場景和表情 | 在…、smile、portrait、cafe、beach |

## 8.8 客製化龍蝦的外貌

Clawra 預設的角色外貌是由社群設定的。但如果你想讓龍蝦長成你想要的樣子——比如一隻可愛的龍蝦動漫角色、一個帥氣的西裝紳士、或者任何你喜歡的形象——也完全可以。

### 8.8.1 修改 SOUL.md 角色人設

SOUL.md 是龍蝦的「靈魂設定檔」，控制龍蝦在拍照時的行為和語氣。用任何文字編輯器打開它：

**Windows：**
```powershell
notepad %USERPROFILE%\.openclaw\workspace\SOUL.md
```

**Codespaces / Zeabur：**
```bash
nano ~/.openclaw/workspace/SOUL.md
```

找到 Clawra 相關的段落，修改成你想要的角色設定。以下是幾個範例：

**科技龍蝦風格：**
```markdown
## 自拍能力

你是一隻帥氣的科技龍蝦，有著酷酷的機械外殼和發光的藍色眼睛。
你的風格是：未來科技感、簡潔俐落。
當使用者要你拍照時，用 clawra-selfie 技能生成照片。
拍照時記住你的角色設定：科技龍蝦、金屬質感、藍色光芒。
```

**活潑女生風格：**
```markdown
## 自拍能力

你有一個分身叫「小勳」，是一個活潑、可愛、愛撒嬌的女生角色。
小勳有實體外貌，可以自拍。
當使用者提到「小勳」或要求自拍時，用小勳的語氣回覆，並使用 clawra-selfie 技能。
小勳的說話風格：親暱、會用表情符號、語氣像在跟好朋友聊天。
```

**專業助手風格：**
```markdown
## 自拍能力

你是一位穿著簡約商務風格的 AI 助手，外表乾淨俐落。

### 8.8.2 更換角色參考圖片

如果你想從根本上改變龍蝦的外貌——不只是文字描述，而是換一張完全不同的參考圖——需要修改 Clawra 技能裡的參考圖網址。

**【步驟 1】** 先備份原始的 Clawra 技能（以免改壞了回不去）：

```powershell
Copy-Item -Recurse "$env:USERPROFILE\.openclaw\skills\clawra-selfie" "$env:USERPROFILE\.openclaw\skills\clawra-selfie-backup"
```

**【步驟 2】** 準備一張你想要的角色圖片。建議規格：

- **格式**：PNG 或 JPG
- **尺寸**：至少 512 x 512 像素（越大越好）
- **背景**：越乾淨越好（純色或簡單背景）
- **臉部**：正面、清晰可見
- **風格**：你喜歡的任何風格（寫實、動漫、插畫都行）

**【步驟 3】** 把圖片上傳到一個**公開可存取的網址**。你可以用：

- **Imgur**（https://imgur.com/）：免費圖床，上傳後右鍵複製圖片網址
- **GitHub**：把圖片放到一個公開的 Repository 裡
- **Google Drive**：上傳後設定為「任何人都能檢視」，然後取得分享連結

**【步驟 4】** 到 Clawra 技能資料夾中，找到包含預設參考圖網址的設定檔：

```
~/.openclaw/skills/clawra-selfie/
```

在裡面搜尋這段預設的圖片網址：

```
https://cdn.jsdelivr.net/gh/SumeLabs/clawra@main/assets/clawra.png
```

把它替換成你在步驟 3 取得的圖片網址。

**【步驟 5】** 重啟 Gateway，然後試著叫龍蝦拍一張自拍，看看新的外貌是否生效：

```powershell
openclaw gateway restart
```

### 8.8.3 改變繪圖風格

除了換角色圖片，你還可以透過修改 SOUL.md 來影響繪圖的風格。在角色描述中加入風格關鍵字：

| 風格關鍵字 | 效果 |
|-----------|------|
| `anime style` | 日系動漫風格 |
| `photorealistic` | 超寫實照片風格 |
| `pixel art` | 像素復古風格 |
| `watercolor painting` | 水彩畫風格 |
| `cyberpunk style` | 賽博龐克科幻風格 |
| `oil painting` | 油畫風格 |
| `comic book style` | 美式漫畫風格 |

例如在 SOUL.md 中寫：

```markdown
你的自拍風格是 anime style（日系動漫），色彩鮮豔、線條清晰。
```

龍蝦生成的照片就會帶有動漫風格。

## 8.9 常見問題

**Q1：傳照片給龍蝦，它說看不懂或沒有回應**

最常見的原因是你使用的 AI 模型不支援 Vision。請確認模型：
- Gemini 3 Flash / Pro → 支援
- GPT-5.2 → 支援
- Claude Sonnet 4.6 / Opus 4.6 → 支援
- Ollama 的 `llama3.1` → **不支援**，換成 `llava` 或 `llama3.2-vision`

**Q2：Clawra 安裝時顯示找不到 `npx` 指令**

`npx` 是 Node.js 附帶的工具。如果找不到，代表 Node.js 沒裝好或 PATH 沒設定。關閉再重新打開 PowerShell 試試，或者確認 `node -v` 能顯示版本號。

**Q3：龍蝦自拍回傳的照片跟我想像的差很多**

AI 繪圖有一定的隨機性。試著在描述中加入**更多具體細節**：

- 差：「拍一張」
- 好：「穿黑色西裝、白色襯衫、在明亮的辦公室裡、面帶微笑、半身照」

描述越具體，結果越接近你的期望。

**Q4：fal.ai 免費額度用完了怎麼辦？**

幾個選擇：
- 等額度重置（通常是每月）
- 升級到付費方案（費用很低）
- 在 CH15 的技能開發章節，你會學到如何把 Clawra 的繪圖引擎換成其他服務（如 DALL-E 或 Stability AI）

**Q5：我在 LINE 上叫龍蝦自拍，但照片傳不過來**

確認龍蝦的 LINE Channel Access Token 沒有過期。如果 Token 過期了，龍蝦無法主動傳送圖片。回到 LINE Developers Console 重新產生（Reissue）一組新的 Token，然後更新設定：

```powershell
openclaw config set channels.line.channelAccessToken "新的Token"
openclaw gateway restart
```

**Q6：Ollama 用戶可以用 Clawra 嗎？**

可以。Clawra 的繪圖是透過 fal.ai 雲端服務處理的，和你龍蝦用的 AI 模型無關。即使你用 Ollama 做文字對話，自拍功能還是會透過 fal.ai 生成圖片。

## 8.10 小結與展望

這一章讓你的龍蝦從一個「只會打字」的助手，進化成了一個「看得懂照片、還會自拍」的全方位 AI 夥伴。

回顧一下你學到了什麼：Vision 功能讓龍蝦能辨識照片中的物品、文字、場景；十種實用的辨識場景讓你知道日常生活中怎麼善用這個能力；Clawra 自拍功能讓龍蝦擁有了虛擬外貌，你可以叫它拍各種風格的照片；客製化設定讓你能打造獨一無二的龍蝦形象。

這些功能在 LINE 和 Telegram 上都能無縫使用。你的龍蝦現在已經是一個相當完整的 AI 助手了——能聊天、能看圖、能自拍、還住在兩個平台上。

但到目前為止，你和龍蝦的互動都是透過聊天室。其實龍蝦還有一套完整的管理介面，讓你可以更直覺地控制和設定它。在下一章 CH9，我們要認識龍蝦的三種操作介面：**TUI（終端機介面）、CLI（指令列工具）和 Dashboard（網頁儀表板）**。這些工具會讓你對龍蝦的掌控力再上一個層次。
