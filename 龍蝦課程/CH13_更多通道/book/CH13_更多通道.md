# CH13 | 更多通道（WhatsApp、Discord 等）

---

到目前為止，你的龍蝦住在 LINE 和 Telegram 這兩個平台上。對大部分台灣使用者來說，這已經夠用了。但你身邊可能有朋友用 WhatsApp、有同事的團隊用 Discord 或 Slack、甚至有人偏好用 Email 跟 AI 互動。

好消息是，OpenClaw 不只是一個 LINE Bot 框架——它是一個**多通道 AI 助手平台**，支援超過 22 種通訊通道。就像一隻章魚有很多觸手一樣，你的龍蝦可以同時伸出很多隻手，守在不同的平台上，而且共用同一個大腦和記憶。

這一章會帶你認識 OpenClaw 支援的所有通道，並實際教你串接 WhatsApp 和 Discord 這兩個最常被問到的平台。

>
> 1. 認識 OpenClaw 支援的 22+ 種通道
> 2. 學會串接 WhatsApp

## 13.1 OpenClaw 支援的通道總覽

### 13.1.1 什麼是「通道」

在 OpenClaw 的架構裡，「通道」（Channel）就是龍蝦跟人類溝通的管道。LINE 是一個通道、Telegram 是一個通道、WhatsApp 也是一個通道。每個通道都是一個「外掛」（Plugin），你想用哪個就安裝哪個。

龍蝦的核心（Gateway + AI 模型）跟通道是分開的：

```
                    ┌─── LINE
                    │
龍蝦核心（AI 大腦）──┼─── Telegram
                    │
                    ├─── WhatsApp
                    │
                    ├─── Discord
                    │
                    └─── ...更多通道
```

所有通道共用同一個 AI 大腦和記憶系統。你在 LINE 上跟龍蝦說的話，龍蝦在 Discord 上也記得（如果你設定了跨通道記憶的話）。

### 13.1.2 通道分類總覽

OpenClaw 支援的通道可以分成幾大類：

**即時通訊類**

| 通道 | 說明 | 適合場景 |

## 13.2 WhatsApp 串接教學

WhatsApp 是全球用戶最多的通訊軟體（超過 20 億用戶）。如果你有在跟國際友人或海外客戶溝通，串接 WhatsApp 會非常有用。

### 13.2.1 事前準備

WhatsApp 的 Bot 串接比 LINE 和 Telegram 稍微複雜一些，因為它需要透過 **Meta（Facebook）的商業平台**。你需要：

- ✅ 一個 Facebook 帳號
- ✅ 一個 Meta Business 帳號（免費申請）
- ✅ 一個電話號碼（用來註冊 WhatsApp Business）
- ✅ 龍蝦已經在本機運行，且有正式域名（CH12）或 ngrok

> ⚠️ **注意**：WhatsApp Business API 有免費額度（每月 1,000 則免費對話），但超過後會收費。學習用完全夠，正式商用要注意費用。

### 13.2.2 申請 Meta Business 帳號

**【步驟 1】** 到 https://business.facebook.com/ 申請 Meta Business 帳號。

**【步驟 2】** 到 https://developers.facebook.com/ 登入開發者帳號。

**【步驟 3】** 建立一個新的 App，類型選 **「Business」**。

**【步驟 4】** 在 App 裡找到 **「WhatsApp」** 產品，點 **「Set up」**。

**【步驟 5】** 按照指引完成 WhatsApp Business 的設定，你會拿到：
- **Phone Number ID**
- **WhatsApp Business Account ID**
- **Permanent Access Token**

記下這三個值，等一下要用。

### 13.2.3 安裝 WhatsApp 外掛

在終端機安裝 WhatsApp 通道外掛：

```powershell
openclaw plugins install @anthropic/whatsapp-channel
```

### 13.2.4 設定 WhatsApp 連線

用 CLI 設定 WhatsApp 的連線資訊：

```powershell
openclaw config set whatsapp.phoneNumberId 你的PhoneNumberID
openclaw config set whatsapp.businessAccountId 你的BusinessAccountID
openclaw config set whatsapp.accessToken 你的AccessToken
openclaw config set whatsapp.webhookUrl https://bot.你的域名.xyz
```

### 13.2.5 設定 Webhook

回到 Meta Developers Console 的 WhatsApp 設定頁面：

**【步驟 1】** 找到 **「Webhooks」** 區塊。

**【步驟 2】** 設定 Callback URL：

```
https://bot.你的域名.xyz/whatsapp/webhook
```

**【步驟 3】** 設定 Verify Token（龍蝦會自動產生，或你可以自訂）。

**【步驟 4】** 訂閱 **「messages」** 事件。

### 13.2.6 重啟並測試

```powershell
openclaw gateway restart
```

用另一支手機的 WhatsApp 傳訊息給你設定的號碼，看看龍蝦有沒有回覆。

## 13.3 Discord 串接教學

Discord 是全球最大的社群平台之一，特別受遊戲玩家和開發者社群歡迎。把龍蝦串上 Discord，它就能在你的 Discord 伺服器裡當助手。

### 13.3.1 事前準備

- ✅ 一個 Discord 帳號
- ✅ 一個你有管理權限的 Discord 伺服器（或自己建一個）
- ✅ 龍蝦已經在本機運行

> 💡 **好消息**：Discord Bot 不需要正式域名（不像 LINE 和 WhatsApp 需要 Webhook）。Discord 用的是 **WebSocket** 連線，龍蝦會主動連到 Discord 的伺服器，不需要外部能連進你的電腦。

### 13.3.2 建立 Discord Bot

**【步驟 1】** 到 Discord Developer Portal：https://discord.com/developers/applications

**【步驟 2】** 點 **「New Application」**，輸入名稱（例如「龍蝦助手」），建立。

**【步驟 3】** 在左側選 **「Bot」** 分頁，點 **「Add Bot」**。

**【步驟 4】** 在 Bot 頁面，點 **「Reset Token」** 產生一組 Bot Token。**複製下來，妥善保管。** 這個 Token 等同於 Bot 的密碼，外洩了別人就能控制你的 Bot。

**【步驟 5】** 在同一頁，開啟以下權限：
- ✅ **Message Content Intent**——讓 Bot 能讀取訊息內容
- ✅ **Server Members Intent**——讓 Bot 能看到伺服器成員（選用）

**【步驟 6】** 在左側選 **「OAuth2」→「URL Generator」**：
- Scopes 勾選 **「bot」**
- Bot Permissions 勾選需要的權限：
  - Send Messages（傳送訊息）
  - Read Message History（讀取訊息歷史）
  - Attach Files（附加檔案）
  - Add Reactions（加反應）

**【步驟 7】** 複製生成的 URL，在瀏覽器開啟，選擇你要加入的伺服器，點 **「Authorize」**。Bot 就會出現在你的 Discord 伺服器裡了。

### 13.3.3 安裝 Discord 外掛

```powershell
openclaw plugins install @anthropic/discord-channel
```

### 13.3.4 設定 Discord 連線

```powershell
openclaw config set discord.botToken 你的BotToken
```

### 13.3.5 重啟並測試

```powershell
openclaw gateway restart
```

到 Discord 伺服器裡的任何文字頻道，@你的 Bot 並打一句話：

```
@龍蝦助手 你好！
```

龍蝦應該會回覆你。

### 13.3.6 Discord 特有的注意事項

- **@提及才回覆**——在 Discord 裡，龍蝦預設只回覆被 @mention 的訊息（跟 LINE 群組行為類似）
- **Markdown 格式不同**——Discord 的 Markdown 不支援表格，龍蝦會自動用條列式取代（AGENTS.md 裡有設定）
- **多伺服器**——同一個 Bot 可以被邀請到多個 Discord 伺服器，龍蝦會分別服務
- **Emoji 反應**——龍蝦可以對訊息加 Emoji 反應，AGENTS.md 裡有相關的行為設定
- **斜線指令**——Discord 支援 `/` 開頭的斜線指令，某些技能可以註冊 Discord 斜線指令

## 13.4 其他通道簡介

### 13.4.1 Slack

Slack 是企業最常用的團隊協作平台。串接方式跟 Discord 類似：

1. 到 https://api.slack.com/apps 建立一個 Slack App
2. 取得 Bot Token
3. 安裝外掛：`openclaw plugins install @anthropic/slack-channel`
4. 設定 Token 和 Webhook
5. 把 App 加入你的 Slack Workspace

Slack Bot 可以在頻道裡被 @mention 回覆，也可以收到私訊。

### 13.4.2 Email

龍蝦也能串接 Email，變成你的自動回信助手：

- 安裝外掛：`openclaw plugins install @anthropic/email-channel`
- 設定 IMAP/SMTP 伺服器資訊（Gmail 的話需要 App Password）
- 龍蝦會定期檢查收件匣，收到新信後根據你的指示回覆

適合場景：自動回覆常見問題、幫你先過濾重要信件、自動歸類郵件。

### 13.4.3 Web Chat（網頁聊天框）

如果你有自己的網站，可以在網頁上嵌入一個聊天框，讓訪客直接跟龍蝦對話：

- 安裝外掛：`openclaw plugins install @anthropic/webchat-channel`
- 龍蝦會提供一段 HTML 嵌入碼
- 把那段碼貼到你的網頁裡就完成了

適合場景：網站客服、產品諮詢、線上教學平台。

### 13.4.4 Facebook Messenger

串接 Facebook Messenger 需要 Meta Business 帳號（跟 WhatsApp 類似）：

- 在 Meta Developers 建立 App，加入 Messenger 產品
- 取得 Page Access Token
- 安裝外掛並設定

適合場景：Facebook 粉絲專頁的自動客服。

### 13.4.5 Microsoft Teams

適合企業環境的使用者：

- 需要 Microsoft 365 帳號和 Azure AD
- 在 Azure Bot Service 建立 Bot
- 安裝外掛並設定

設定流程較複雜，適合有 IT 支援的企業用戶。

## 13.5 常見問題

**Q1：裝了這麼多通道，龍蝦會變慢嗎？**

不太會。每個通道只是一個「接訊息的管道」，真正消耗資源的是 AI 模型的回覆。你裝十個通道但只有一個人在用，跟裝一個通道是一樣的負載。但如果很多人同時從不同通道傳訊息，回覆可能會稍微排隊。

**Q2：不同通道的對話記憶是共通的嗎？**

取決於你的設定。預設情況下，龍蝦會認每個使用者——如果你在 LINE 和 Discord 上配對的是同一個人（透過配對碼），龍蝦知道是同一個人。但每個通道的對話脈絡（短期記憶）是分開的，長期記憶（USER.md、MEMORY.md）是共用的。

**Q3：我只用 LINE，其他通道都不需要，可以嗎？**

當然可以。大部分台灣使用者只用 LINE 就夠了。這一章的通道都是「有需要再裝」，不是必須的。

**Q4：WhatsApp 的免費額度用完了怎麼辦？**

WhatsApp Business API 每月有 1,000 則免費對話。超過後會依照 Meta 的定價收費（不同國家費率不同）。學習用通常夠，正式商用要到 Meta Business 後台查看費率。

**Q5：Discord Bot 可以同時在多個伺服器運行嗎？**

可以。一個 Discord Bot 可以被邀請到多個伺服器，龍蝦會分別服務每個伺服器。每個伺服器的對話是獨立的。

## 13.6 小結與展望

這一章帶你看到了 OpenClaw 強大的多通道能力。你的龍蝦不只是一個 LINE Bot——它是一個可以住在任何通訊平台上的 AI 助手。

我們實際串接了 WhatsApp 和 Discord，也介紹了 Slack、Email、Web Chat 等通道。重點不是把所有通道都裝起來，而是知道龍蝦**有這個能力**——當你需要的時候，隨時可以擴充。

但目前為止，不管你裝了多少個通道，它們背後都是**同一隻龍蝦**。如果你想要「一隻龍蝦當工作秘書、另一隻龍蝦當學習夥伴」呢？在下一章 CH14，我們要教你龍蝦的**多重分身**——讓多隻龍蝦各自有不同的人設、不同的專長，各司其職。
