## 16.1 排程提醒——HEARTBEAT.md 基礎

### 16.1.1 什麼是 Heartbeat

Heartbeat（心跳）是 OpenClaw 的「定時巡邏」機制。你可以在 HEARTBEAT.md 裡寫下龍蝦要定期做的事，龍蝦就會像一個盡責的管家一樣，每隔一段時間自動去做。

不需要你手動提醒，不需要你傳訊息觸發——龍蝦會**主動**去做，然後在需要的時候通知你。

### 16.1.2 HEARTBEAT.md 的位置和格式

檔案位置：`~/.openclaw/workspace/HEARTBEAT.md`

格式很簡單，就是用自然語言寫下你要龍蝦做的事：

```markdown
# HEARTBEAT.md

## 每日任務

- 每天早上 08:00，查詢台北天氣，用一段簡短的話告訴我今天的天氣和穿衣建議
- 每天早上 08:30，查看我的 Google Calendar 今日行程，列出今天有哪些會議或活動
- 每天晚上 21:00，問我今天過得怎麼樣

## 每週任務

- 每週一早上 09:00，幫我整理這週的待辦事項清單
- 每週五下午 17:00，回顧這週完成了什麼，給我一個小小的鼓勵

## 提醒事項

- 3/15 提醒我繳信用卡帳單
- 4/1 提醒我愚人節不要被騙
```

### 16.1.3 Heartbeat 的運作方式

龍蝦會定期「醒來」檢查 HEARTBEAT.md（頻率取決於你的設定，通常每 15-30 分鐘一次）。每次醒來它會：

1. 讀取 HEARTBEAT.md
2. 判斷現在是否有任務需要執行
3. 如果有，執行任務並透過 LINE / Telegram 通知你
4. 如果沒有，安靜地繼續睡（回覆 `HEARTBEAT_OK`）

### 16.1.4 Heartbeat vs Cron

OpenClaw 還有另一種排程機制叫 Cron（精確定時）。兩者的差別：

| | Heartbeat | Cron |
|---|-----------|------|
| **精確度** | 大約（±15 分鐘） | 精確到分鐘 |
| **設定方式** | 自然語言寫在 HEARTBEAT.md | 指令設定 |
| **適合** | 批次檢查、不需要精確時間的任務 | 精確時間的提醒、一次性任務 |
| **API 消耗** | 較少（批次處理） | 較多（每個任務獨立呼叫） |

**建議**：日常使用 Heartbeat 就夠了。需要「幾點幾分準時」的提醒再用 Cron。

### 16.1.5 實用範例：早安助理

設定一個完整的「早安助理」，每天早上自動提供資訊：

```markdown
# HEARTBEAT.md

## 早安助理（每天 07:30-08:00 之間執行）

每天早上幫我做以下事情，整合成一則訊息傳給我：

1. 查詢台北今天的天氣（溫度、降雨機率、穿衣建議）
2. 查看 Google Calendar 今天有什麼行程
3. 如果今天有會議，提醒我準備什麼
4. 用一句簡短的話幫我開啟美好的一天

格式範例：
🌤️ 早安！今天 26°C，多雲。帶傘出門比較保險。
📅 今天行程：10:00 部門會議 / 14:00 客戶拜訪
💡 記得帶上週五整理的報告去開會！
```

## 16.2 天氣查詢

### 16.2.1 安裝和設定

如果你還沒裝天氣技能：

```powershell
clawdhub install weather
```

在 TOOLS.md 裡加上設定：

```markdown
## Weather
- API Key: 你的_OpenWeatherMap_API_Key
- 預設城市: 台北
- 溫度單位: 攝氏
```

重啟 Gateway：

```powershell
openclaw gateway restart
```

### 16.2.2 日常使用方式

裝好之後，你可以用各種自然的方式問天氣：

```
你：今天天氣如何？
龍蝦：🌤️ 台北今天 26°C，多雲偶陣雨，降雨機率 40%。
      建議帶把折疊傘，穿薄長袖即可。
```

```
你：東京這週末天氣好嗎？
龍蝦：📍 東京週末天氣預報：
      週六：22°C，晴天 ☀️
      週日：20°C，多雲 ⛅
      非常適合出門！不太需要帶傘。
```

```
你：明天適合洗車嗎？
龍蝦：🚗 明天台北有 70% 機率下午會下雨，
      建議後天再洗比較划算！
```

龍蝦不只是回報數字——它會根據天氣資訊給你**實用的建議**。這就是 AI + 技能的威力。

### 16.2.3 搭配 Heartbeat

把天氣整合進 HEARTBEAT.md，每天自動收到天氣通知：

```markdown
- 每天早上 07:30，查台北天氣，特別提醒是否需要帶傘、穿外套
- 如果明天氣溫驟降超過 5 度，提前在今天晚上通知我
```

## 16.4 Notion 整合

### 16.4.1 為什麼要整合 Notion

Notion 是很多人用來管理筆記、待辦事項、專案的工具。整合龍蝦之後，你可以直接在 LINE 上跟龍蝦說話來操作 Notion——不用打開 Notion App、不用開電腦。

例如：

```
你（走在路上，用 LINE）：幫我在 Notion 的待辦清單加一筆「買牛奶」
龍蝦：✅ 已加入 Notion 待辦清單：買牛奶
```

### 16.4.2 安裝和設定

```powershell
clawdhub install notion
```

**取得 Notion API Key：**

**【步驟 1】** 到 https://www.notion.so/my-integrations 建立一個 Integration。

**【步驟 2】** 取得 Internal Integration Token（以 `ntn_` 開頭的字串）。

**【步驟 3】** 到你想讓龍蝦存取的 Notion 頁面，點右上角「⋯」→「Add connections」→ 選你剛建立的 Integration。

**【步驟 4】** 在 TOOLS.md 裡加上：

```markdown
## Notion
- API Token: ntn_你的Token
- 待辦清單資料庫 ID: 你的資料庫ID
- 筆記資料庫 ID: 你的資料庫ID
```

> 💡 **怎麼找資料庫 ID**：在 Notion 網頁版打開你的資料庫頁面，網址裡 `notion.so/` 後面到 `?` 之前的那串字就是資料庫 ID。

### 16.4.3 日常使用方式

```
你：幫我在 Notion 加一筆待辦：明天交報告
龍蝦：✅ 已新增到 Notion 待辦清單：
      📝 明天交報告
      📅 截止日期：2026/03/08
```

```
你：我的 Notion 待辦清單有什麼？
龍蝦：📋 你的待辦清單（3 筆未完成）：
      1. ❌ 明天交報告（截止：3/8）
      2. ❌ 買牛奶
      3. ❌ 回覆客戶 Email
      要標記哪一筆為完成嗎？
```

```
你：第 2 筆完成了
龍蝦：✅ 已將「買牛奶」標記為完成！
      還剩 2 筆未完成。
```

## 16.5 Google Calendar 整合

### 16.5.1 為什麼要整合 Google Calendar

Google Calendar 大概是最多人用的行事曆。整合龍蝦之後，你可以用說的來管行程：

- 「幫我加一筆行程：下週三下午兩點開會」
- 「我明天有什麼事？」
- 「幫我把週五的會議改到週一」

不用打開 Calendar App，在 LINE 上說一句話就搞定。

### 16.5.2 安裝和設定

```powershell
clawdhub install google-calendar
```

**取得 Google Calendar API 權限：**

**【步驟 1】** 到 Google Cloud Console（https://console.cloud.google.com/）。

**【步驟 2】** 建立一個新專案（或使用現有的）。

**【步驟 3】** 在左側選單找到 **「API 和服務」→「程式庫」**，搜尋並啟用 **「Google Calendar API」**。

**【步驟 4】** 到 **「API 和服務」→「憑證」**，建立一個**服務帳號**。

**【步驟 5】** 建立服務帳號後，在「金鑰」分頁建立一組 **JSON 金鑰**，下載 JSON 檔案。

**【步驟 6】** 把 JSON 檔案放到工作區：

```powershell
Copy-Item 下載的金鑰.json C:\Users\你的名稱\.openclaw\workspace\google-credentials.json
```

**【步驟 7】** 到 Google Calendar 的設定裡，把服務帳號的 Email（在 JSON 裡的 `client_email` 欄位）加為行事曆的共用對象，權限設為「可編輯」。

**【步驟 8】** 在 TOOLS.md 裡加上：

```markdown
## Google Calendar
- 憑證路徑: ~/.openclaw/workspace/google-credentials.json
- 主要行事曆: primary
- 提醒提前時間: 30 分鐘
```

### 16.5.3 日常使用方式

```
你：明天有什麼行程？
龍蝦：📅 明天（3/8 週六）的行程：
      09:00-10:00  牙醫回診
      14:00-16:00  讀書會
      晚上沒有安排，可以好好休息！
```

```
你：幫我加一筆行程，下週二下午三點跟小明開會，一個小時
龍蝦：✅ 已新增行程：
      📅 3/11（二）15:00-16:00
      📝 跟小明開會
      要設定提前 30 分鐘提醒嗎？
```

```
你：要
龍蝦：✅ 已設定提醒，會在 14:30 通知你。
```

### 16.5.4 搭配 Heartbeat

```markdown
- 每天早上 07:30，查看今天的 Google Calendar 行程，如果有會議就提醒我
- 每個行程開始前 30 分鐘，主動通知我
- 每週日晚上，預告下週的行程安排
```

## 16.6 其他實用應用

### 16.6.1 簡易記帳

不需要特別的技能，龍蝦用 AI 本身的能力加上筆記功能就能幫你記帳：

```
你：記一筆，午餐便當 80 元
龍蝦：✅ 已記錄：
      📆 2026/03/07
      🍱 午餐便當：$80
      今日累計：$280
```

```
你：這個月花了多少？
龍蝦：💰 3 月支出統計（截至 3/7）：
      🍽️ 餐飲：$2,340
      🚗 交通：$1,200
      🛒 日用品：$860
      📱 其他：$450
      ─────────
      合計：$4,850
```

龍蝦會把記帳資料存在記憶檔案裡。如果你搭配 Notion 技能，還能自動同步到 Notion 的記帳資料庫。

## 16.7 常見問題

**Q1：HEARTBEAT.md 的任務沒有執行**

幾個可能的原因：
- Heartbeat 功能沒有啟用——在 AGENTS.md 裡確認 Heartbeat 相關設定有開啟
- Gateway 沒有在跑——Heartbeat 需要 Gateway 持續運行
- 時間還沒到——Heartbeat 不是精確定時的，可能有 ±15 分鐘的誤差
- HEARTBEAT.md 格式有問題——確保是合法的 Markdown 格式

**Q2：天氣技能回覆的城市不對**

在 TOOLS.md 裡設定預設城市。如果你問天氣時沒有指定城市，龍蝦會用預設城市。你也可以每次問的時候明確說「台北天氣」。

**Q3：Notion 連不上**

確認以下事項：
- API Token 是否正確（以 `ntn_` 開頭）
- 你有沒有把 Integration 加入到 Notion 頁面的 connections 裡
- 資料庫 ID 是否正確

**Q4：Google Calendar 沒有反應**

設定步驟比較多，最常見的問題是：
- JSON 金鑰路徑錯誤——確認檔案在工作區裡
- 服務帳號沒有被加為行事曆的共用對象——到 Google Calendar 設定裡加
- Google Calendar API 沒有啟用——到 Google Cloud Console 確認

**Q5：這些技能會消耗很多 API 費用嗎？**

大部分技能的 API 都有免費額度：
- OpenWeatherMap：每分鐘 60 次，免費
- NewsAPI：每天 100 次，免費
- Notion API：免費
- Google Calendar API：每天 1,000,000 次，基本上用不完

真正消耗費用的是 AI 模型的 API（Gemini / GPT / Claude）。但正常使用每天幾十到幾百則對話，費用很低。

## 16.8 小結與展望

這一章讓你的龍蝦從一個「聊天助手」進化成了「生活管家」：

- **排程提醒**——HEARTBEAT.md 讓龍蝦每天主動為你做事
- **天氣查詢**——出門前自動告訴你帶不帶傘
- **新聞摘要**——每天五分鐘掌握今日大事
- **Notion 整合**——在 LINE 上一句話管理待辦事項
- **Google Calendar**——用說的管理行程
- **記帳、翻譯、食譜**——各種生活小幫手

這些應用的關鍵不是技術有多難，而是**養成習慣**。一開始你可能還是會習慣自己打開天氣 App、自己開 Notion。但用了一兩週之後，你會發現跟龍蝦說一句話比自己操作快太多了。

但目前為止，你用的都是別人做好的技能。如果你想要的功能沒有現成的技能呢？在下一章 CH17，我們要教你**自己開發技能**。別被「開發」這個詞嚇到——其實就是寫一個 Markdown 檔案，比你想像的簡單得多。
