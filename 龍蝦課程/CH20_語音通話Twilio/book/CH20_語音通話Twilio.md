# CH20 | 語音通話（Twilio）

---

到目前為止，你跟龍蝦的互動都是靠「文字」——你打字，它回文字。即使是 LINE 的語音訊息，本質上也是語音辨識轉成文字後再處理。

但你有沒有想過，直接**打電話給龍蝦**？

想像一下這些場景：

- 你開車的時候想問龍蝦事情，不方便打字，直接打電話問
- 你的長輩不會用 LINE 打字，但會打電話——讓他們打電話就能跟龍蝦聊天
- 你在外面需要龍蝦幫你查資料，拿起手機撥個號碼就搞定
- 你想做一個語音客服機器人，接聽客戶來電自動回答問題

這就是 OpenClaw 的 **Twilio 語音通話**功能——給龍蝦一個電話號碼，讓它能接打電話。

> **本章學習目標**
>
> 1. 認識 Twilio 的功能和費用
> 2. 學會申請 Twilio 帳號和電話號碼
> 3. 設定龍蝦接聽語音通話
> 4. 了解語音通話的實際應用場景

## 20.1 Twilio 是什麼

### 20.1.1 通訊平台即服務

Twilio 是全球最大的「通訊平台即服務」（CPaaS）公司。簡單說，它讓開發者可以透過 API 來打電話、傳簡訊、傳 WhatsApp 訊息等。

你不需要了解電話系統的底層技術——Twilio 把這些都包裝成簡單的 API。OpenClaw 的語音通話功能就是透過 Twilio 來實現的。

### 20.1.2 Twilio 能做什麼

| 功能 | 說明 |
|------|------|
| **接聽電話** | 給龍蝦一個電話號碼，使用者打來龍蝦自動接聽 |
| **撥打電話** | 龍蝦主動撥打電話給指定號碼 |
| **語音辨識** | 來電者說的話，即時轉成文字給龍蝦 |
| **語音合成** | 龍蝦的文字回覆，用語音唸出來給來電者聽 |
| **簡訊** | 龍蝦也可以收發 SMS 簡訊（本章聚焦語音） |

### 20.1.3 費用說明

Twilio 不是免費的——它是商業服務。但費用比你想像的低：

| 項目 | 費用（美元） | 說明 |
|------|------------|------|
| **電話號碼** | $1.15/月 | 美國號碼月租費 |
| **接聽電話** | $0.0085/分鐘 | 每分鐘不到 0.3 台幣 |
| **語音辨識** | $0.02/15 秒 | Twilio 內建的 STT |
| **語音合成** | 免費~$0.01/句 | 看你用哪種 TTS |
| **撥打電話** | $0.014/分鐘 | 撥打美國號碼 |

> 💡 **免費試用**：Twilio 新帳號有免費額度（約 $15），足夠你測試和學習。你不需要一開始就花錢。

台灣號碼也有，但月租費較高（約 $11/月）。如果只是學習和測試，用美國號碼就夠了。

## 20.2 申請 Twilio 帳號

### 20.2.1 註冊帳號

1. 到 https://www.twilio.com/try-twilio 註冊
2. 填寫 Email、密碼
3. 驗證手機號碼（台灣的 +886 號碼可以用）
4. 回答幾個問題（選「Voice」和「With code」）
5. 完成註冊，進入 Console

### 20.2.2 取得 Account SID 和 Auth Token

在 Twilio Console 首頁就能看到兩個重要的東西：

```
Account SID：AC1234567890abcdef...
Auth Token：（點擊眼睛圖示顯示）
```

把這兩個值記下來，等下要填到 OpenClaw 裡。

> ⚠️ **Auth Token 是密碼等級的敏感資訊**，不要分享給任何人，不要放到 GitHub 上。

### 20.2.3 購買電話號碼

1. 在 Console 左側選單點 **Phone Numbers → Manage → Buy a number**
2. 選擇國家（建議選美國 United States，最便宜）
3. 勾選「Voice」能力
4. 選一個你喜歡的號碼，按 **Buy**
5. 試用帳號免費買一個號碼

恭喜，你的龍蝦現在有電話號碼了！

## 20.3 設定龍蝦接聽語音通話

### 20.3.1 安裝 Twilio 外掛

```powershell
openclaw plugins install twilio-voice
```

安裝完成後，設定 Twilio 的認證資訊：

### 20.3.2 設定認證資訊

在 TOOLS.md 裡加上：

```markdown
## Twilio（語音通話）
- Account SID: 你的_Account_SID
- Auth Token: 你的_Auth_Token
- 電話號碼: +1xxxxxxxxxx（你買的號碼）
- 語音語言: zh-TW（中文）
- TTS 引擎: google（Google 語音合成）
```

或用 CLI 設定：

```powershell
openclaw config set twilio.accountSid 你的_Account_SID
openclaw config set twilio.authToken 你的_Auth_Token
openclaw config set twilio.phoneNumber +1xxxxxxxxxx
openclaw config set twilio.language zh-TW
```

### 20.3.3 設定 Webhook

跟 LINE 的 Webhook 類似，Twilio 也需要一個 Webhook 來接收來電通知。

如果你用 Cloudflare Tunnel（CH12），在 `config.yml` 裡加上 Twilio 的路由：

```yaml
ingress:
  - hostname: lobster.你的域名.com
    service: http://localhost:18789
  - service: http_status:404
```

然後到 Twilio Console 設定：

1. 進入 **Phone Numbers → Manage → Active numbers**
2. 點擊你的號碼
3. 在 **Voice Configuration** 區塊：
   - **A call comes in** → **Webhook**
   - URL 填入：`https://lobster.你的域名.com/twilio/voice`
   - 方法選 **POST**
4. 按 **Save configuration**

### 20.3.4 重啟 Gateway

```powershell
openclaw gateway restart
```

### 20.3.5 測試通話

拿起手機，撥打你買的 Twilio 號碼。你應該會聽到：

```
（電話接通）
龍蝦：你好！我是龍蝦，有什麼可以幫你的嗎？

你（說話）：今天台北天氣怎麼樣？

龍蝦（語音回覆）：今天台北 26 度，多雲偶陣雨，
       出門建議帶把傘喔！

你：謝謝，掰掰。

龍蝦：掰掰，有需要隨時打來！
（掛斷）
```

如果你聽到龍蝦的聲音回答你——恭喜，語音通話設定成功了！

## 20.4 語音通話的運作原理

### 20.4.1 通話流程

當有人打電話給龍蝦，背後發生的事情是：

```
1. 你撥打 Twilio 號碼
2. Twilio 接聽，通知 OpenClaw（透過 Webhook）
3. OpenClaw 送出歡迎語（TTS 語音合成→播放給你聽）
4. 你開始說話
5. Twilio 即時語音辨識（STT），把你的話轉成文字
6. OpenClaw 把文字送給 AI 模型處理
7. AI 產生回覆文字
8. TTS 把回覆轉成語音，播放給你聽
9. 重複 4-8 直到掛斷
```

整個過程的延遲大約 1-3 秒——你說完話後，龍蝦需要一兩秒才會回答。比打字聊天稍微慢一點，但完全可以接受。

### 20.4.2 語音辨識（STT）

Twilio 支援多種語音辨識引擎：

| 引擎 | 中文支援 | 準確度 | 費用 |
|------|---------|--------|------|
| Twilio 內建 | ✅ zh-TW | 中等 | 包含在通話費裡 |
| Google STT | ✅ zh-TW | 高 | 額外計費 |
| Deepgram | ✅（有限） | 高 | 額外計費 |

建議先用 Twilio 內建的，夠用了。如果覺得辨識不夠準確再升級。

### 20.4.3 語音合成（TTS）

讓龍蝦「說話」的引擎也有多種選擇：

| 引擎 | 中文音質 | 自然度 | 費用 |
|------|---------|--------|------|
| Twilio 內建 | 一般 | ★★☆ | 免費 |
| Google TTS | 好 | ★★★ | 低 |
| ElevenLabs | 很好 | ★★★★ | 中 |
| OpenAI TTS | 很好 | ★★★★ | 中 |

如果你想要更自然的聲音，可以在 TOOLS.md 裡設定使用 ElevenLabs 或 OpenAI TTS：

```markdown
## TTS（語音合成）
- 引擎: elevenlabs
- API Key: 你的_ElevenLabs_API_Key
- 語音: 中文女聲（Rachel）
- 語速: 1.0
```

## 20.5 實際應用場景

### 20.5.1 個人語音助手

最基本的用法——把龍蝦當成你的語音助手：

```
你（打電話）：幫我查一下明天下午有什麼行程？
龍蝦：你明天下午有兩個行程：
      兩點鐘要開專案會議，
      四點半要跟王老師見面。
      需要幫你調整嗎？

你：把四點半的改到五點。
龍蝦：好的，已經把跟王老師的見面改到五點了。
      還有什麼事嗎？

你：沒了，謝謝。
龍蝦：好的，掰掰！
```

### 20.5.2 長輩友善介面

很多長輩不會用 LINE 打字，但他們很會打電話。給他們一個號碼，就能跟龍蝦對話：

```
（阿公打電話）
龍蝦：你好！我是龍蝦小助手，有什麼可以幫您的嗎？

阿公：明天天氣怎麼樣？要不要帶傘？
龍蝦：明天台中 22 度，有小雨喔，出門記得帶傘。
      後天就放晴了。

阿公：那後天呢？
龍蝦：後天台中 26 度，大太陽，很適合出門走走！

阿公：好，謝謝你啊。
龍蝦：不客氣，祝您身體健康！隨時打來喔。
```

### 20.5.3 語音客服機器人

如果你是開店或做小生意的，可以用龍蝦來接聽客戶來電：

```
（客戶打電話）
龍蝦：您好，歡迎致電小明咖啡店，
      我是 AI 助手，請問有什麼可以幫您的？

客戶：你們今天有營業嗎？
龍蝦：有的，今天營業時間是早上 9 點到晚上 9 點。

客戶：有沒有座位？我想訂位。
龍蝦：現在還有 3 個空桌。
      請問您幾位？什麼時候到？

客戶：2 位，大概下午 3 點。
龍蝦：好的，已幫您預約下午 3 點 2 位。
      請問貴姓？
```

要實現這種客服功能，你需要在 SKILL.md 裡定義店家的資訊和訂位邏輯。

### 20.5.4 電話提醒

搭配 HEARTBEAT.md，龍蝦可以主動打電話提醒你：

```markdown
# HEARTBEAT.md 裡的設定

## 每日提醒電話
- 時間: 08:00
- 動作: 撥打 +886912345678
- 內容: 報告今日行程和天氣
```

早上八點，你的手機響了：

```
龍蝦：早安！今天是 3 月 8 號星期六。
      天氣 24 度，多雲。
      你今天有一個行程：下午 2 點要去看牙醫。
      祝你有美好的一天！
```

> ⚠️ **注意**：主動撥打電話會產生通話費用（按分鐘計費），建議控制頻率。

## 20.6 進階設定

### 20.6.1 通話錄音

你可以設定通話自動錄音，方便回顧：

```markdown
## Twilio 進階設定
- 通話錄音: 開啟
- 錄音儲存位置: ~/.openclaw/workspace/data/recordings/
- 錄音保留天數: 30
```

### 20.6.2 來電黑名單

避免騷擾電話：

```markdown
## 來電管理
- 黑名單: +886900000000, +886911111111
- 白名單模式: 關閉（設為開啟則只接白名單的電話）
```

### 20.6.3 通話時長限制

避免意外產生高額費用：

```markdown
## 通話限制
- 最長通話時間: 10 分鐘
- 每日通話上限: 30 分鐘
- 超過限制: 禮貌提醒後掛斷
```

## 20.7 常見問題

**Q1：台灣的手機可以打 Twilio 的美國號碼嗎？**

可以，但會產生國際通話費（依你的電信方案而定）。建議使用 LINE Out 或其他 VoIP 服務來撥打，費用更低。另外，Twilio 也提供台灣號碼（+886 開頭），但月租較高。

**Q2：語音辨識聽不懂台灣國語怎麼辦？**

Twilio 的中文語音辨識設定語言為 `zh-TW` 會使用繁體中文模型，對台灣口音的辨識效果還不錯。如果辨識率不高，可以：
- 說慢一點、清楚一點
- 升級到 Google STT 引擎（辨識率更高）
- 在安靜的環境通話

**Q3：通話中可以請龍蝦操作電腦嗎？**

可以！語音通話和 Desktop Agent（CH18）可以搭配。你打電話跟龍蝦說「幫我打開瀏覽器查一下明天的航班」，龍蝦就會在你的電腦上執行，然後語音回報結果。

**Q4：可以多人同時打電話嗎？**

Twilio 支援同時接聽多通電話。每通電話是獨立的對話，不會互相干擾。但每通電話都會佔用 AI 的處理資源和產生 Twilio 費用。

**Q5：不用 Twilio 有其他選擇嗎？**

目前 OpenClaw 官方支援的語音通話方案是 Twilio。社群有在開發其他方案（例如 SIP 整合、WebRTC 直接通話），但目前還在早期階段。

## 20.8 小結與展望

這一章讓你的龍蝦學會了「說話」：

- **Twilio 帳號**——註冊、取得 SID/Token、購買電話號碼
- **語音通話設定**——安裝外掛、設定 Webhook、測試通話
- **通話原理**——STT 語音辨識 + AI 處理 + TTS 語音合成
- **實際應用**——個人助手、長輩友善、客服機器人、電話提醒

你的龍蝦現在是一個真正的全方位 AI 助手了——能打字聊天、能看圖片、能操控電腦、能打電話。

但如果這些能力都是「你叫它做」才做呢？在最後一章 CH21，我們要教你打造一隻**全自動的龍蝦**——不用你開口，它就會主動幫你做事。每天自動報天氣、到時間自動提醒行程、收到特定訊息自動處理。這就是「自動化與排程」的威力。
