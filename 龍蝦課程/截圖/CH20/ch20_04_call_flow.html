🎤 STT 語音轉文字引擎 Speech-to-Text

  • Google Cloud Speech-to-Text（預設，支援中文）
  • Deepgram（低延遲、即時串流轉錄）
  • OpenAI Whisper（高精準度離線方案）
  • Azure Speech Services（微軟方案）

🔊 TTS 文字轉語音引擎 Text-to-Speech

  • Google Cloud TTS（預設，自然語調）
  • ElevenLabs（最自然、情感豐富）
  • OpenAI TTS（高品質多語言）
  • Azure Neural TTS（微軟神經網路語音）

☁️ Twilio 平台角色 Twilio

  • 提供虛擬電話號碼（可選各國號碼）
  • 透過 Webhook 將來電轉給龍蝦伺服器
  • 使用 TwiML 指令控制通話流程
  • 支援錄音、轉接、多方通話等功能
