各代能力說明

💻
第一代 Coding Agent
只能在編輯器裡幫你寫程式、修 bug。無法跳出程式碼的世界。
🌐
第二代 Browser Agent
可以打開瀏覽器、點選網頁、填表單，但僅限於瀏覽器內操作。
🖥️
第三代 Desktop Agent
可以操作桌面應用程式（如 Word、Excel），但各功能是分開的。
🦞
第四代 Computer Agent（OpenClaw）
融合前三代所有能力！能寫程式、開瀏覽器、操作桌面，還能用你的真實帳號登入服務、自主規劃工作流程。
