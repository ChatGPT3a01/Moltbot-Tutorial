Browser Sandbox 概念圖

龍蝦操作瀏覽器的兩種模式 — 沙盒隔離 vs 直接操控

模式 A
🛡️
沙盒模式（安全模式）
Sandbox Browser
🦞 龍蝦 AI 下達瀏覽器指令
📦 沙盒瀏覽器 隔離環境，獨立運作
不碰你的真實瀏覽器
🌐 目標網站 以全新身分訪問
優點與限制
  • 安全隔離，不影響你的瀏覽器
  • 全自動執行，無需人工介入
  • 不怕搞亂你的書籤或設定
  • 看不到你已登入的帳號
  • 無法存取瀏覽器的 Cookie
  • 需要另外登入網站帳號
VS
模式 B
🎯
直接模式
Peekaboo + Real Browser
🦞 龍蝦 AI 下達桌面操作指令
👁️ Peekaboo 桌面操控中介層
截圖 + 滑鼠 + 鍵盤
🖥️ 你的真實瀏覽器 Chrome / Edge / Firefox
保有你的登入狀態
🌐 目標網站 以你的帳號身分訪問
優點與限制
  • 可使用你已登入的帳號
  • 看到真實畫面，所見即所得
  • 能操作任何桌面應用程式
  • 需注意安全規則（別亂按）
  • 操作時螢幕會被佔用
  • 需要安裝 Peekaboo 工具
🛡️
適合場景：自動化任務
爬資料、填表單、測試網頁
不需要帳號登入的自動化工作
🎯
適合場景：帳號操作
管理 Google 日曆、操作 LINE
需要你的登入身分的任務
