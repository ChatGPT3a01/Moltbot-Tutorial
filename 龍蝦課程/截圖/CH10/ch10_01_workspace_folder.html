📂 OpenClaw 工作區資料夾結構
  • ▼ 📁 .openclaw/ ← 龍蝦的家目錄（隱藏資料夾）
  • ▼ 📁 workspace/ ← 工作區核心，所有設定都在這裡
  • 📄 IDENTITY.md ← 龍蝦的身份與人格設定（名字、個性、說話風格）
  • 📄 SOUL.md ← 龍蝦的行為準則（什麼該做、什麼不該做）
  • 📄 USER.md ← 你的個人偏好（語言、稱呼、回覆風格）
  • 📄 AGENTS.md ← 分身代理設定（多角色切換）
  • 📄 TOOLS.md ← 環境與工具設定（系統資訊、路徑）
  • 📄 HEARTBEAT.md ← 排程與自動化（定時提醒、排程任務）
  • 📁 skills/ ← 已安裝的技能（每個技能一個資料夾）
  • 📁 dashboard/ ← Dashboard 網頁管理介面
  • ⚙️ openclaw.json ← 主要設定檔（API Key、LINE 頻道、模型選擇）
