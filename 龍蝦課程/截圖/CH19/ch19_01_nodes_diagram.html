Primary Node vs Worker Node 角色對比

比較項目 Primary Node 主控節點 Worker Node 工作節點
部署位置 雲端伺服器（如 GitHub Codespaces、VPS） 本地電腦（家裡桌機、辦公室筆電等）
運行時間 24 小時不間斷運行 需要時才開機，可隨時上下線
主要職責 接收用戶訊息、AI 推理、任務分派與結果彙整 執行 Primary 指派的具體任務（截圖、檔案、列印等）
通訊管道 直接對接 LINE / Telegram 等 Webhook 僅與 Primary 通訊，不直接面對用戶
硬體需求 低（僅需網路和基本運算） 依任務而定（可利用本地 GPU、印表機等資源）
安全性 持有 API 金鑰、管道憑證 僅持有與 Primary 通訊的加密金鑰
數量 通常 1 台 可多台，各自負責不同能力
離線影響 全系統停擺，用戶無法互動 僅該 Worker 負責的任務暫停，其餘正常
