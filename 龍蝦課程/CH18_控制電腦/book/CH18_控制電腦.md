# CH18 | 控制電腦

---

到目前為止，龍蝦一直住在「聊天室」裡——你傳訊息，它回訊息。但你有沒有想過，龍蝦如果能走出聊天室，直接在你的電腦上幫你做事呢？

想像一下這些場景：

- 你在外面用手機傳 LINE 給龍蝦說「幫我打開瀏覽器查一下明天的航班」，龍蝦就真的在你家電腦上打開瀏覽器，查好航班資訊回覆你
- 你跟龍蝦說「幫我把桌面上的照片整理到相簿資料夾」，龍蝦就自動幫你移檔案
- 你跟龍蝦說「幫我把那份 Excel 轉成 PDF」，龍蝦就幫你處理好

這不是科幻電影——這是 OpenClaw 的 **Desktop Agent（桌面代理）** 功能。龍蝦可以像一個遠端助手一樣，直接操控你的電腦。

> **本章學習目標**
>
> 1. 認識 Desktop Agent 的概念和能力範圍
> 2. 了解瀏覽器操控（Browser Sandbox）的運作方式
> 3. 學會用龍蝦進行檔案管理自動化
> 4. 認識應用程式自動化的可能性
> 5. 理解安全注意事項

## 18.1 Desktop Agent 概念

### 18.1.1 什麼是 Desktop Agent

Desktop Agent 是 AI 自主代理的一種進階形態。在 CH0 我們介紹過 Agent 的四代演進：

| 世代 | 類型 | 能力 |
|------|------|------|
| 第一代 | Coding Agent | 寫程式、操作終端機 |
| 第二代 | Browser Agent | 瀏覽網頁、填表單 |
| 第三代 | Desktop Agent | 操控電腦上的應用程式 |
| 第四代 | Computer Agent | 完全自主操控整台電腦 |

龍蝦的 Desktop Agent 能力介於第二代和第三代之間——它可以操控瀏覽器、管理檔案、執行腳本，但還不到「完全自主操控整台電腦」的程度。

### 18.1.2 Desktop Agent 能做什麼

| 能力 | 範例 |
|------|------|
| **瀏覽網頁** | 打開網站、搜尋資訊、擷取內容 |
| **檔案管理** | 建立、複製、移動、重新命名檔案和資料夾 |
| **執行程式** | 跑 Python 腳本、PowerShell 指令 |
| **讀寫文件** | 讀取 PDF、Word、Excel，產生報告 |
| **螢幕截圖** | 截取螢幕畫面分析 |
| **系統操作** | 查看系統資源、管理程序 |

### 18.1.3 Desktop Agent 的限制

需要注意的是，Desktop Agent **不是萬能的**：

- 它不能操作「有圖形介面但沒有 API」的軟體（例如直接點 PhotoShop 的按鈕）
- 它主要透過命令列和 API 來操作，不是「看著螢幕點滑鼠」
- 複雜的操作可能需要多次嘗試
- 每次操作都需要你的授權（除非你明確設定自動執行）

## 18.2 瀏覽器操控（Browser Sandbox）

### 18.2.1 什麼是 Browser Sandbox

Browser Sandbox 讓龍蝦可以操控一個「沙盒瀏覽器」——一個在安全環境中運行的瀏覽器。龍蝦可以在裡面打開網頁、點擊連結、填寫表單、擷取資訊。

「沙盒」的意思是這個瀏覽器跟你平常用的瀏覽器是隔離的——龍蝦不會動到你 Chrome 裡的書籤、密碼和瀏覽紀錄。

### 18.2.2 瀏覽器能做什麼

**場景一：查資料**

```
你（LINE）：幫我查一下台北到花蓮的火車時刻，明天早上的
龍蝦：讓我查一下...
      🚂 明天（3/8）台北→花蓮 早上班次：
      06:30 太魯閣號 410 次（2h15m）
      07:00 自強號 208 次（2h40m）
      08:00 太魯閣號 412 次（2h15m）
      要我幫你查票價嗎？
```

**場景二：擷取資訊**

```
你：幫我看看 PTT 的八卦版今天有什麼熱門文章
龍蝦：📋 PTT 八卦版今日熱門（前 5 篇）：
      1. [爆卦] xxx（推：587）
      2. [問卦] xxx（推：423）
      3. [新聞] xxx（推：356）
      ...
```

**場景三：填表單**

```
你：幫我到 Google Forms 填那份問卷，
    第一題選 A，第二題填「台北市」，第三題選滿意
龍蝦：✅ 已完成填寫，最後一步需要你確認送出。
      要我幫你送出嗎？
```

### 18.2.3 設定瀏覽器操控

瀏覽器操控需要安裝 Playwright 或 Puppeteer（自動化瀏覽器工具）：

```powershell
# 安裝瀏覽器操控技能
clawdhub install browser-sandbox

# 安裝 Playwright 瀏覽器
npx playwright install chromium
```

在 TOOLS.md 裡加上：

```markdown
## Browser Sandbox
- 瀏覽器: Chromium
- 無頭模式: 是（不會彈出瀏覽器視窗）
- 截圖: 每次操作後自動截圖回報
```

## 18.3 檔案管理自動化

### 18.3.1 基本檔案操作

龍蝦可以直接在你的電腦上操作檔案：

```
你：桌面上有多少個 PDF 檔？
龍蝦：📁 桌面上有 12 個 PDF 檔案：
      - 會議記錄_0301.pdf (2.3MB)
      - 報價單.pdf (156KB)
      - 教案_CH5.pdf (890KB)
      ...（共 12 個）
```

```
你：把桌面上所有的 PDF 移到「文件/PDF」資料夾
龍蝦：即將移動 12 個 PDF 檔案到「文件/PDF」資料夾。
      確認執行嗎？
你：確認
龍蝦：✅ 已移動 12 個檔案到 C:\Users\你的名稱\Documents\PDF\
```

### 18.3.2 智慧整理

龍蝦不只能做簡單的搬移——它可以用 AI 理解檔案的內容來分類：

```
你：幫我整理下載資料夾，把檔案分類到不同的子資料夾
龍蝦：📂 掃描完成，下載資料夾共 47 個檔案。
      建議分類如下：
      📁 文件（PDF、Word、Excel）→ 18 個
      📁 圖片（JPG、PNG）→ 12 個
      📁 壓縮檔（ZIP、RAR）→ 8 個
      📁 安裝檔（EXE、MSI）→ 5 個
      📁 其他 → 4 個
      要執行嗎？
```

### 18.3.3 磁碟盤點

CH15 提到的 `disk-audit` 技能就是一個檔案管理的例子：

```
你：幫我掃描 D 槽，找出佔最多空間的前 10 個檔案
龍蝦：🔍 掃描中...
      📊 D 槽 Top 10 大檔案：
      1. 遊戲安裝檔.iso (4.7GB)
      2. 備份_202601.zip (2.1GB)
      3. 教學影片.mp4 (1.8GB)
      ...
      總共佔用 15.3GB。要處理哪一個？
```

## 18.4 應用程式自動化

### 18.4.1 透過腳本自動化

龍蝦可以執行 PowerShell 和 Python 腳本，間接操控其他應用程式：

**範例一：自動產生 PDF**

```
你：幫我把桌面上的 report.md 轉成 PDF
龍蝦：正在轉換...
      ✅ 已產生 report.pdf，放在同一個資料夾裡。
```

龍蝦背後是呼叫了 `md-to-pdf` 之類的轉換工具。

**範例二：Excel 資料處理**

```
你：幫我打開 sales.xlsx，算出每個月的銷售總額
龍蝦：📊 sales.xlsx 銷售總額統計：
      1月：$125,000
      2月：$142,000
      3月：$168,000（截至 3/7）
      ─────────
      Q1 累計：$435,000
      要我產生圖表嗎？
```

**範例三：批次重新命名**

```
你：幫我把「照片」資料夾裡的檔案，
    全部改名成「旅遊_日期_序號」的格式
龍蝦：📁 找到 85 張照片。
      我會根據照片的拍攝日期（EXIF 資訊）重新命名。
      例如：IMG_0001.jpg → 旅遊_20260215_001.jpg
      確認執行嗎？
```

### 18.4.2 系統管理

```
你：我的電腦最近很慢，幫我看看什麼東西佔最多記憶體
龍蝦：🖥️ 目前記憶體使用狀況：
      總共 16GB，已使用 13.2GB（82%）

      Top 5 吃記憶體的程式：
      1. Chrome（32 個分頁）→ 4.1GB
      2. VS Code → 1.2GB
      3. Discord → 800MB
      4. Teams → 650MB
      5. Node.js（龍蝦 Gateway）→ 180MB

      建議：Chrome 的分頁太多了，要幫你列出哪些分頁最久沒用嗎？
```

## 18.5 安全注意事項

Desktop Agent 的能力很強大，但**能力越大責任越大**。讓 AI 操控你的電腦有一些安全風險需要注意。

### 18.5.1 預設的安全機制

OpenClaw 的 Desktop Agent 有幾層安全防護：

1. **確認機制**——涉及檔案刪除、移動、修改的操作，龍蝦會先問你確認
2. **沙盒隔離**——瀏覽器操作在沙盒裡進行，不會影響你的正常瀏覽器
3. **範圍限制**——龍蝦只能存取你授權的資料夾，不是整台電腦
4. **日誌記錄**——所有操作都有 log，你可以回顧龍蝦做了什麼

### 18.5.2 你應該做的事

**設定安全邊界**

在 AGENTS.md 或 SOUL.md 裡明確設定龍蝦可以操作的範圍：

```markdown
## Desktop Agent 安全規則

### 可以自由操作的區域
- 桌面
- 文件資料夾
- 下載資料夾
- 工作區（~/.openclaw/workspace/）

### 需要確認才能操作的區域
- 其他磁碟（D:、E: 等）
- 應用程式資料夾

### 絕對不能碰的區域
- Windows 系統目錄（C:\Windows\）
- Program Files
- 其他使用者的資料夾
- 任何含有密碼或金鑰的檔案
```

**用 trash 不用 delete**

在 AGENTS.md 裡已經有這條規則：「trash > rm（可復原勝過永遠消失）」。這表示龍蝦刪除檔案時，會移到資源回收桶而不是永久刪除。

**定期檢查日誌**

透過 Dashboard 或 CLI 查看龍蝦的操作日誌，確認它沒有做出你不預期的事。

### 18.5.3 不建議做的事

- ❌ 讓龍蝦自動登入你的銀行帳號
- ❌ 把整台電腦的管理員權限給龍蝦
- ❌ 讓龍蝦在沒有確認的情況下刪除檔案
- ❌ 讓龍蝦操作含有敏感資料的軟體（密碼管理器等）

## 18.6 常見問題

**Q1：Desktop Agent 功能需要額外安裝嗎？**

需要安裝對應的技能。瀏覽器操控裝 `browser-sandbox`、檔案管理裝 `file-manager`、系統監控裝 `system-monitor`。每個功能都是獨立的技能。

**Q2：我不在電腦旁邊，龍蝦可以操作我的電腦嗎？**

可以，只要你的電腦開著、Gateway 在跑。你可以在外面用手機 LINE 傳指令給龍蝦，它會在你的電腦上執行。這就是 Desktop Agent 最酷的地方——遠端遙控你的電腦。

**Q3：龍蝦會不會誤刪重要檔案？**

預設會先確認才執行。而且刪除操作會移到資源回收桶，不是永久刪除。即使龍蝦真的誤操作了，你也可以從資源回收桶救回來。

**Q4：我的電腦效能會被影響嗎？**

瀏覽器操控（Playwright）會佔用一些記憶體（約 200-500MB），但只在執行瀏覽器任務時才會啟動。檔案管理和系統操作基本上不影響效能。

**Q5：Mac 和 Linux 也支援嗎？**

支援。Desktop Agent 的核心是透過命令列和 API 操作，所以跨平台都能用。差別在於 PowerShell 指令要換成 Mac/Linux 的 Shell 指令，但龍蝦會自動判斷你的作業系統。

## 18.7 小結與展望

這一章讓你的龍蝦走出了聊天室，進入了你的電腦：

- **Browser Sandbox** 讓龍蝦能瀏覽網頁、查資料、填表單
- **檔案管理** 讓龍蝦能整理檔案、掃描磁碟、批次處理
- **應用程式自動化** 讓龍蝦能轉檔、處理資料、管理系統
- **安全機制** 確保龍蝦不會亂動你的東西

你的龍蝦現在真的是一個「全方位 AI 助手」了——不只會聊天，還會幫你做事。

但如果你有好幾台電腦呢？一台在家裡、一台在辦公室、一台是雲端伺服器——你想讓龍蝦同時管理所有的機器。在下一章 CH19，我們要教你 OpenClaw 的 **Nodes（多機協作）** 功能，讓多台電腦上的龍蝦串成一個網路，互相合作。
