# CH3 | Claude Code 快速上手

---

你有沒有過這種經驗：明明只是要改一個設定檔裡的一個數字，你卻花了二十分鐘才找到那個檔案在哪裡、又花了五分鐘搞懂哪一行要改、再花三分鐘擔心自己改錯了會不會出事？

如果旁邊有一個人，他對你的電腦瞭若指掌——你說「幫我把 config 裡的 port 改成 18789」，他三秒鐘就改好了，還順便跟你說「改好了，我順便確認了格式沒有問題」。那該有多省事？

Claude Code 就是那個人。

只不過，它住在你的**終端機**裡。

終端機就是那個黑底白字的命令列視窗，你可能在電影裡看過駭客在上面飛快敲鍵盤。聽起來很嚇人，但實際上使用 Claude Code 一點都不需要像駭客。你只要用中文跟它聊天，告訴它你要做什麼，它就會幫你在電腦上執行操作。讀檔案、改檔案、搜尋內容、管理版本——全部用對話完成。

在上一章，我們學了 Antigravity 這個有圖形介面的 AI 工程師。現在讓我們認識另一位夥伴——沒有花俏畫面、但做事又快又精準的 AI 終端機特助。

## 3.1 Claude Code 是什麼

---

### 3.1.1 住在終端機裡的 AI 特助

Claude Code 是 Anthropic 公司推出的終端機 AI 助手。所謂「終端機」，就是那個讓你輸入指令、按 Enter 執行的命令列視窗。在 Windows 上，它叫做 PowerShell 或 Command Prompt；在 macOS 上，它叫做 Terminal。

跟 Antigravity 的最大差別是：Claude Code **沒有圖形介面**。沒有漂亮的按鈕、沒有拖拉放、沒有所見即所得。一切都是文字——你打字問它，它打字回你，中間穿插著它在你電腦上執行的各種操作。

這聽起來好像比 Antigravity 弱？恰恰相反。

正因為 Claude Code 直接在終端機裡運作，它可以執行**任何**你在命令列上能做的事情。安裝軟體、修改系統設定、批次處理檔案、操作 Git、執行腳本——這些對 Claude Code 來說都是家常便飯。而且因為不需要載入圖形介面，它的**反應速度非常快**，改一個檔案通常在一秒內就完成了。

### 3.1.2 Claude Code 擅長什麼

| 場景 | 用 Antigravity | 用 Claude Code |
|------|---------------|----------------|
| 從零做一個網頁 | ✅ 更適合（有預覽） | 可以做但看不到即時預覽 |
| 修改一個設定檔 | 可以但有點大材小用 | ✅ 更適合（快速精準） |
| 批次重命名 100 個檔案 | 不太方便 | ✅ 更適合（一個指令搞定） |
| Git 操作（commit、push） | 可以但步驟多 | ✅ 更適合（用對話就好） |
| 除錯一段程式碼 | ✅ 兩者都適合 | ✅ 兩者都適合 |
| 安裝和設定軟體 | 可以 | ✅ 更適合（直接執行指令） |
| 理解整個專案的結構 | 可以 | ✅ 更適合（快速掃描全部檔案） |

簡單的選擇原則：**要「建造」新東西，用 Antigravity；要「操作」現有的東西，用 Claude Code。** 當然，兩者的能力有大量重疊，很多時候用哪個都行。隨著你越來越熟練，你會自然地知道什麼情況下該用哪個。

## 3.2 安裝 Claude Code

---

讓我們開始動手。安裝 Claude Code 的過程非常簡單，總共只需要三個步驟。

### 3.2.1 前置條件：安裝 Node.js

Claude Code 需要 Node.js 才能運行。如果你的電腦上還沒有安裝 Node.js，現在來裝一下。

**【步驟 1】** 打開瀏覽器，前往 Node.js 官網：

```
https://nodejs.org/
```

**【步驟 2】** 你會看到兩個下載按鈕。選擇左邊的 **LTS**（長期支援版），點擊下載。

**【步驟 3】** 下載完成後，執行安裝程式。一路按「Next」、「I agree」、「Install」就好，不需要更改任何設定。

**【步驟 4】** 安裝完成後，打開 PowerShell（按 `Windows 鍵`，搜尋 `PowerShell`，點開它），輸入：

```powershell
node --version
```

如果看到類似 `v22.x.x` 或 `v24.x.x` 的版本號碼，就表示安裝成功了。

> 💡 **已經裝過 Node.js 了？** 如果你之前已經裝過（比如在其他課程中），只要版本是 v18 以上就可以。輸入 `node --version` 檢查一下就好。

![Node.js 安裝成功確認](../截圖/ch3_node_version.png)

### 3.2.2 安裝 Claude Code

Node.js 裝好之後，接下來安裝 Claude Code 本身。在 PowerShell 裡輸入：

```powershell
npm install -g @anthropic-ai/claude-code
```

這行指令的意思是：用 npm（Node.js 的套件管理工具）在全系統範圍安裝 Claude Code。安裝過程可能需要一到兩分鐘，取決於你的網路速度。

安裝完成後，輸入以下指令確認：

```powershell
claude --version
```

如果看到版本號碼（例如 `1.0.x`），恭喜，Claude Code 安裝成功了。

![Claude Code 安裝成功](../截圖/ch3_claude_install.png)

### 3.2.3 首次啟動與登入

現在來啟動 Claude Code。在 PowerShell 裡輸入：

```powershell
claude
```

第一次啟動時，Claude Code 會要求你登入。它會提供幾種登入方式：

- **Anthropic API Key**：如果你在 CH1 已經申請了，選這個，把 `sk-ant-` 開頭的 Key 貼上去
- **Anthropic 帳號登入**：透過瀏覽器授權
- **訂閱方案**：如果你有 Claude Pro / Max 訂閱

選擇你方便的方式完成登入。登入之後，你會看到一個簡潔的對話介面——一個輸入游標在等你打字。

```
╭────────────────────────────────────────╮
│  Claude Code                           │
│                                        │
│  Type your message...                  │
│                                        │
╰────────────────────────────────────────╯
```

這就是 Claude Code 的全部介面了。沒有按鈕、沒有選單、沒有側邊欄。只有你和 AI 之間的對話。

> 💡 **Claude Code 的操作邏輯**：你輸入一句話（中文或英文都行），按 Enter 送出。Claude Code 會理解你的意圖，然後在你的電腦上執行對應的操作。它可能會讀取檔案、修改內容、執行指令——然後把結果回報給你。

![Claude Code 首次啟動畫面](../截圖/ch3_claude_first_launch.png)

## 3.3 基本對話操作

---

安裝好了，讓我們來熟悉 Claude Code 的基本用法。最好的學習方式就是實際動手，所以接下來我會帶你做幾個簡單的練習。

### 3.3.1 練習一：打個招呼

先試試最簡單的——跟 Claude Code 聊天。在對話框裡輸入：

```
你好，請用中文跟我說話
```

按 Enter 送出。Claude Code 會用中文回覆你。這個操作跟 ChatGPT 一樣，只是發生在終端機裡。

### 3.3.2 練習二：問它一個問題

試試問它一些跟你電腦相關的問題：

```
我的電腦上有裝 Node.js 嗎？是什麼版本？
```

Claude Code 不會只用「猜」的來回答你。它會**真的去你的電腦上執行** `node --version` 這個指令，然後把結果告訴你。你可以在畫面上看到它執行了什麼指令、得到了什麼結果。

這就是 Claude Code 跟一般聊天機器人最大的不同：**它不只是回答問題，它會直接在你的電腦上行動**。

### 3.3.3 練習三：探索資料夾

讓我們再進一步。假設你想知道目前所在的資料夾裡有哪些檔案：

```
幫我看一下目前這個資料夾裡有什麼
```

Claude Code 會列出所有的檔案和子資料夾，通常還會附上簡短的說明，告訴你每個檔案大概是做什麼用的。

> 💡 **Claude Code 的工作目錄**：Claude Code 啟動時，會以你在 PowerShell 裡所在的目錄作為起點。所以如果你想讓它操作某個特定的資料夾，可以先用 `cd` 指令切換過去，再啟動 Claude Code。例如：
> ```powershell
> cd D:\Moltbot
> claude
> ```

## 3.4 檔案操作

---

Claude Code 最實用的能力之一，就是幫你操作檔案。讀取、修改、建立、搜尋——全部用對話就能完成，不需要自己打開檔案、找到那一行、小心翼翼地修改。

### 3.4.1 讀取檔案

假設你想看某個設定檔的內容：

```
幫我讀取 config.json 的內容
```

Claude Code 會把檔案的完整內容顯示出來，而且通常會附上它的理解：「這是一個 OpenClaw 的設定檔，裡面包含了 LINE 通道的設定、AI 模型的設定等等。」

### 3.4.2 修改檔案

這是最常用的操作。比如你想改一個設定值：

```
幫我把 config.json 裡的 port 從 3000 改成 18789
```

Claude Code 會先讀取檔案、找到那一行、修改數值、然後存檔。整個過程可能在兩秒內就完成了。它還會告訴你它改了什麼、改之前是什麼、改之後變成什麼——讓你確認沒有改錯。

> ⚠️ **安全機制**：Claude Code 在修改檔案或執行可能影響系統的指令之前，通常會先跟你確認。你會看到一個提示，問你「是否允許這個操作？」你可以選擇允許或拒絕。這是一個很好的安全設計，防止 AI 不小心改壞東西。

### 3.4.3 建立新檔案

```
幫我在目前的資料夾裡建立一個 hello.txt，內容寫「這是我用 Claude Code 建立的第一個檔案」
```

Claude Code 會建好檔案，你可以用檔案總管打開確認。

### 3.4.4 搜尋內容

如果你想在一大堆檔案裡找某段文字：

```
幫我在這個專案裡搜尋所有包含 "API_KEY" 的檔案
```

Claude Code 會快速掃描所有檔案，列出哪些檔案的哪幾行包含這個關鍵字。這在大型專案裡特別好用——自己一個一個打開檔案找，可能要花半小時；用 Claude Code，三秒鐘搞定。

## 3.5 Git 版本控制

---

如果你不知道什麼是 Git，讓我用一個比喻來解釋：Git 就是你檔案的「時光機」。

想像你在寫一份重要的報告。你寫完第一版，存了一個檔案叫 `report.docx`。後來你改了很多內容，又存了一版叫 `report_v2.docx`。再後來又改了，存成 `report_final.docx`。最後你又改了，存成 `report_final_真的final.docx`......這種混亂的版本管理，大家一定都經歷過。

Git 就是為了解決這個問題而存在的。它會幫你記住每一次修改的歷史——你什麼時候改了什麼、為什麼改。如果改壞了，你可以隨時「回到過去」，恢復到任何一個之前的版本。

而且最棒的是：有了 Claude Code，你完全不需要學 Git 的指令。你只要用中文告訴它你想做什麼就好。

### 3.5.1 初始化 Git

如果你的資料夾還沒有被 Git 管理，先讓 Claude Code 幫你初始化：

```
幫我在目前的資料夾初始化 Git
```

Claude Code 會執行 `git init`，建立一個 Git 倉庫。

### 3.5.2 儲存一個版本（Commit）

當你對目前的檔案狀態滿意了，想「存檔」一個版本：

```
幫我把所有修改 commit 起來，訊息寫「完成首頁設計」
```

Claude Code 會幫你：
1. 把所有修改過的檔案加入暫存區（`git add`）
2. 建立一個 commit，附上你指定的訊息（`git commit`）

> 💡 **Commit 訊息的意義**：每次 commit 都附上一個簡短的說明，記錄這次你做了什麼改動。日後回頭看歷史的時候，你就能快速知道每個版本的內容。好的 commit 訊息像日記一樣，讓你的「時光旅行」更有效率。

### 3.5.3 查看歷史紀錄

```
幫我看一下最近的 Git 歷史紀錄
```

Claude Code 會列出最近的幾次 commit，包含時間、作者和訊息。

### 3.5.4 回到之前的版本

如果你不小心改壞了什麼東西：

```
幫我看一下上一次 commit 的時候 config.json 長什麼樣子
```

Claude Code 會從 Git 歷史中取出舊版本的檔案內容給你看。如果你確定要復原：

```
幫我把 config.json 恢復到上一次 commit 的版本
```

這就是 Git 的「時光機」功能。有了它，你永遠不用擔心「改壞了回不去」。

## 3.6 Voice Mode：用說的

---

2026 年 3 月，Claude Code 新增了一個令人興奮的功能：**Voice Mode（語音模式）**。你可以按住空白鍵，用說的來跟 Claude Code 對話，而不需要打字。

### 3.6.1 啟動 Voice Mode

在 Claude Code 的對話介面中，按住鍵盤上的**空白鍵（Space）**不放，就會進入語音模式。你會看到畫面上出現一個麥克風的指示，表示正在錄音。

對著麥克風說出你的需求（中文即可），說完後放開空白鍵。Claude Code 會把你的語音轉換成文字，然後像平常一樣執行操作。

### 3.6.2 什麼時候用 Voice Mode

Voice Mode 特別適合以下情況：

- **手邊在忙其他事**：比如你在看著另一份文件，想同時讓 Claude Code 做事
- **長篇描述**：有時候用說的比打字快，特別是描述複雜的需求時
- **行動不便時**：暫時不方便打字的情況

使用範例：

> 你（按住空白鍵說）：「幫我在 workspace 資料夾裡面找到 SOUL.md 這個檔案，然後把裡面小勳的描述改成『活潑、調皮、喜歡撒嬌的女生角色』」

Claude Code 會把這段語音轉成文字，然後自動找到檔案、修改內容。

> 💡 **語音辨識的準確度**：Claude Code 的語音辨識支援中文，但偶爾會有誤聽的情況（特別是專有名詞）。如果它辨識錯了，你可以直接用打字的方式補充修正。

## 3.8 Claude Code 的斜線指令

---

除了自然語言對話之外，Claude Code 還有一些以 `/` 開頭的**斜線指令（Slash Commands）**，可以快速執行特定操作：

| 指令 | 功能 | 什麼時候用 |
|------|------|-----------|
| `/help` | 顯示說明文件 | 不確定怎麼操作的時候 |
| `/clear` | 清除對話歷史 | 想重新開始的時候 |
| `/compact` | 壓縮對話記憶 | 對話太長、反應變慢時 |
| `/cost` | 顯示目前的 API 使用量 | 想確認花了多少錢時 |
| `/doctor` | 診斷 Claude Code 的設定 | 遇到問題的時候 |

你不需要記住所有指令。最常用的就是 `/help`（不知道怎麼用的時候）和 `/clear`（想重新來過的時候）。

雖然 Claude Code 的主戰場是終端機，但它也可以跟 VS Code 搭配使用。如果你習慣用 VS Code 寫程式，這個整合會讓你的體驗更順暢。

這種搭配方式結合了兩者的優點：VS Code 的圖形介面讓你一目了然地看到檔案結構和內容，Claude Code 的對話式操作讓你不用自己動手修改。

## 3.10 常見問題與疑難排解

---

**問題 1：安裝時出現 permission error**

在 Windows 上，有時候 npm 安裝全域套件會碰到權限問題。解決方式是**用系統管理員身份開啟 PowerShell**：右鍵點擊 PowerShell → 選擇「以系統管理員身份執行」，然後重新跑安裝指令。

**問題 2：claude 指令找不到**

安裝完之後如果輸入 `claude` 說找不到指令，試試關掉 PowerShell 然後重新打開。有時候系統需要重新載入路徑設定。

**問題 3：API Key 餘額不足**

如果 Claude Code 回覆「Rate limit exceeded」或類似訊息，表示你的 API 額度用完了。到 Anthropic Console 檢查餘額，必要時加值。

**問題 4：Claude Code 修改了我不想改的東西**

不要慌。Claude Code 在執行修改前通常會徵求你的同意。如果它已經改了，你可以：
- 按 `Ctrl+Z`（如果你在 VS Code 裡看那個檔案）
- 或跟 Claude Code 說「幫我撤銷剛才的修改」
- 或用 Git 回到之前的版本

**問題 5：對話紀錄太長，反應變慢**

輸入 `/compact` 讓 Claude Code 壓縮對話記憶，或輸入 `/clear` 清除全部紀錄重新開始。

## 3.11 Antigravity vs Claude Code：如何選擇

---

到目前為止，你已經認識了兩個強大的 AI 工具。你可能會想：「這兩個有些功能重疊，我什麼時候該用哪個？」

讓我給你一個簡單的決策框架：

```
你的任務是什麼？
│
├─ 要「建造」新東西（網頁、應用程式、專案）
│   └→ 用 Antigravity（有預覽、有多 Agent）
│
├─ 要「操作」現有的東西（改設定、管檔案、跑指令）
│   └→ 用 Claude Code（快速、精準、直接）
│
├─ 要除錯或解決問題
│   └→ 兩個都行，看你手邊開著哪個
│
└─ 不確定
    └→ 先試 Claude Code（啟動快、輕量）
```

實際上，很多進階用戶會**兩個同時用**：用 Antigravity 的 Manager View 派出多個 Agent 同時建立多個功能，同時用 Claude Code 在終端機裡做細部的設定調整和 Git 操作。兩個工具搭配起來，效率非常驚人。

在後面的章節裡，我們安裝和設定 OpenClaw 的時候，你會看到兩個工具輪流上陣的場景。到時候你就能更具體地感受到它們各自的長處了。
