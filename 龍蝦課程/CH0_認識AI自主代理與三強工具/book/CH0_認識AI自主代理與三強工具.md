## 0.1 什麼是自主代理 AI

---

### 0.1.1 從聊天機器人到自主代理

你一定用過 ChatGPT 或 Gemini 吧？打開網頁，輸入一個問題，AI 回答你。你再問一個，它再回答一個。這個來回的過程，就是所謂的「聊天機器人」——你問一句，它答一句。

這樣的工具已經很厲害了。但如果你仔細想想，會發現它有一個根本性的限制：**它永遠在等你**。你不問，它就不動。你關掉網頁，它就消失。它不會自己去做任何事情。

現在，讓我們換一個場景來想：

- 「能不能讓 AI **自己去查**今天的新聞，**自己整理**好，每天早上 8 點**自動傳到我的 LINE**？」
- 「能不能讓 AI **自己打開**我的電腦，**自己操作**瀏覽器，幫我完成一項報名手續？」
- 「能不能讓 AI **自己讀**我的 Email，判斷哪些重要，**自動回覆**那些制式的信件？」

這些事情，聊天機器人做不到。但有一種新型態的 AI 可以——它叫做**自主代理 AI（Autonomous Agent）**。

用一個生活化的比喻來理解：聊天機器人就像一本百科全書，你每次翻開查一個問題，查完就闔上。而自主代理 AI，更像是一個住在你家的**私人管家**。你早上出門前交代一句：「幫我處理今天的事。」等你回到家，所有事情都已經搞定了。

下面這張表可以幫你更清楚地看出三者的差異：

| 類型 | 比喻 | 你需要做的事 |
|------|------|-------------|
| 聊天機器人 | 百科全書 | 每次翻開查一個問題 |
| AI 助手（如 Siri） | 語音遙控器 | 每次說一個指令 |
| **自主代理 AI** | **私人管家** | **交代一次，它自己安排好所有事** |

自主代理 AI 之所以能做到這些，是因為它不只是「回答問題」，它還具備了幾個關鍵能力：它能**主動執行任務**，比如你設定「每天早上查天氣」，它就每天自動做；它能**使用各種工具**，像是上網搜尋、操作瀏覽器、讀寫檔案、發送訊息；它能**跨平台工作**，同時在 LINE、Telegram、Email 上幫你處理事情；它甚至能**記住你的偏好**，知道你喜歡什麼格式、什麼語氣、什麼時間接收訊息。

> 💡 **一句話總結**：聊天機器人是「你問它答」，自主代理是「你交代，它自己去完成」。

### 0.1.2 自主代理能做什麼——四個真實場景

光講概念可能還是有點抽象，讓我用四個真實的使用場景，帶你感受一下自主代理 AI 的威力。這些場景在你讀完這本書之後，全部都能實現。

**場景一：忙碌的老師**

阿亮老師每天早上起床，LINE 上已經收到龍蝦整理好的訊息：今天的天氣預報、教育新聞摘要、今天的行事曆提醒、昨天未讀的重要 Email。這些全部是龍蝦在凌晨五點**自動完成**的，阿亮老師不需要打開任何 App，拿起手機就能掌握今天的一切。

**場景二：遠端工作者**

小明人在咖啡廳工作，突然想到家裡電腦上有一份重要文件。他打開 Telegram，跟龍蝦說：「幫我截圖桌面，看看那個 PDF 在不在。」幾秒後，龍蝦透過**遠端控制**截了一張桌面的圖傳回來。小明看到文件確實在，又說：「幫我把它上傳到 Google Drive。」龍蝦照做了——整個過程，小明完全不需要回家開電腦。

**場景三：創意工作者**

小美在 LINE 上輸入：「小勳～穿白色洋裝在花園拍一張。」龍蝦的虛擬女友分身「小勳」用撒嬌的語氣回覆：「好啊～等我換好衣服就拍給你 😘」然後自動用 AI 生成一張虛擬形象照片，直接傳回 LINE 聊天室。沒錯，龍蝦不只能做正經事，還能陪你玩。

**場景四：團隊協作**

一個 LINE 群組裡同時有三個龍蝦 Bot：「小助」負責回答工作問題、「小編」負責寫社群文案、「小勳」負責搞笑和拍照。同事們在群組裡 @ 不同的 Bot，各自處理不同的事情。這就是多重分身的力量——一個龍蝦帳號可以分裂成多個角色，各司其職。

看完這四個場景，你應該能感受到：自主代理 AI 不是遙遠的未來科技，它是現在就能用的東西。而這本書要做的，就是手把手教你建立屬於你自己的 AI 管家。

## 0.2 Agent 世代演進

---

在深入認識我們的三個工具之前，讓我們先用宏觀的角度看看 AI Agent（AI 代理人）這個領域的發展歷程。了解這段歷史，能幫你理解為什麼 OpenClaw 這麼特別，以及為什麼我們說它是「第四代」。

### 0.2.1 第一代：Coding Agent（寫程式）

AI Agent 的故事，要從 2023 年說起。那一年，GitHub Copilot 和後來的 Cursor 等工具開始流行，它們的能力是**幫你寫程式碼**。你在編輯器裡打字，AI 會自動補全程式碼、產生函式、甚至幫你除錯。

舉例來說，你輸入「幫我寫一個計算 BMI 的函式」，AI 就會立刻生成完整的程式碼。這在當時已經非常驚人了——程式設計師的生產力一下子提升了好幾倍。

但第一代 Agent 有一個很明顯的限制：**它只會在編輯器裡工作**。你叫它上網搜尋？不行。你叫它開個瀏覽器？不行。你叫它傳個訊息？更不行。用比喻來說，它就像一個打字超快的助理——你說要什麼，它馬上打出來，但它只會打字，不會幫你跑腿。

### 0.2.2 第二代：Browser Agent（操作瀏覽器）

很快地，開發者們不滿足於只能寫程式碼的 AI 了。到了 2024 年，Browser Use、Playwright AI 等工具出現，讓 AI 多了一項新能力：**操作瀏覽器**。它能打開網頁、點按鈕、填表單、擷取網頁上的資料。

比如你說「幫我到 Google 搜尋今天的台積電股價」，AI 會自動打開 Chrome、輸入搜尋關鍵字、找到結果、把數字擷取回來給你。這是一個巨大的進步——AI 終於從編輯器裡「走出來」了。

不過，第二代 Agent 也有限制：它只會用瀏覽器。你叫它打開 Word？不行。你叫它操作桌面上的其他 App？也不行。就像一個助理學會了自己上網查資料，但在網路以外的世界，它什麼都不會。

### 0.2.3 第三代：Desktop Agent（操作桌面）

2025 年，Anthropic 推出了 Computer Use 功能，Apple 推出了 Apple Intelligence，AI Agent 的能力再次升級：**它可以操作你整個桌面了**。它能看到你的螢幕畫面、移動滑鼠游標、點擊任何應用程式的按鈕。

你跟它說「幫我打開 Word，建立一份新文件，標題打『會議紀錄』」，它就會真的自己打開 Word、新增文件、輸入標題。這已經非常接近一個真人助理在你旁邊幫你操作電腦了。

但第三代 Agent 仍有一道牆：**它只能操作你面前這台電腦**。它不能主動傳訊息給你的朋友、不能跨裝置工作、也不能在你關機後繼續運行。你人不在電腦前，它就什麼也做不了。

### 0.2.4 第四代：Computer Agent — OpenClaw

終於，我們來到第四代——也就是本書的主角 **OpenClaw（龍蝦 AI）**。

第四代 Agent 打破了所有前面世代的限制。它把前三代的能力全部整合在一起，還加入了前所未有的新功能。下面這張對比表可以讓你一目了然：

| 能力 | 第一代 | 第二代 | 第三代 | **第四代 OpenClaw** |
|------|--------|--------|--------|-------------------|
| 寫程式碼 | ✅ | ✅ | ✅ | ✅ |
| 操作瀏覽器 | ✗ | ✅ | ✅ | ✅ |
| 操作桌面 | ✗ | ✗ | ✅ | ✅ |
| **多通道通訊** | ✗ | ✗ | ✗ | ✅ LINE / Telegram / WhatsApp 等 22 個 |
| **24 小時運行** | ✗ | ✗ | ✗ | ✅ 你關機它也能回你訊息 |
| **多機協作** | ✗ | ✗ | ✗ | ✅ 同時控制多台電腦和手機 |
| **技能擴充** | ✗ | ✗ | ✗ | ✅ 60+ 官方技能，還能自己開發 |
| **語音通話** | ✗ | ✗ | ✗ | ✅ 能用電話打給你 |
| **記憶系統** | ✗ | ✗ | ✗ | ✅ 記住你的偏好和對話歷史 |

簡單來說，第四代 Agent 就是一個**永遠在線的私人管家**。你隨時可以透過 LINE 或 Telegram 交代事情，它會自己去做、做完回報給你。你甚至可以用手機遙控它去操作家裡的電腦。它是目前 AI Agent 領域的最強型態。

**OpenClaw 的誕生故事**

說到這裡，讓我簡短介紹一下 OpenClaw 的身世。它由奧地利開發者 **Peter Steinberger** 創建，2026 年 1 月底正式問世後迅速爆紅，短短幾週內就成為全球最受關注的開源 AI 專案之一。它的前身叫做 Clawdbot，後來改名為 Moltbot，最終定名為 OpenClaw。Peter 後來加入了 OpenAI，但 OpenClaw 始終維持**完全免費、開源**的精神——任何人都可以下載來用，不收一毛錢。

> 💡 **為什麼叫龍蝦？** OpenClaw 的「Claw」是爪子的意思。因為龍蝦最大的特徵就是那對大爪子，所以台灣的社群就親切地幫它取了暱稱——「龍蝦 AI」🦞。這本書裡，我們也會用「龍蝦」來稱呼它。

### 0.3.1 OpenClaw 龍蝦 AI — 你的 AI 管家

OpenClaw 是一個永遠在線的 AI 管家，你透過 LINE、Telegram 等通訊軟體跟它對話，它就會幫你處理各種大小事。它不是一個網頁、不是一個 App，而是一個跑在你電腦（或雲端伺服器）上的**常駐服務**，24 小時不間斷地等待你的指令。

| 項目 | 說明 |
|------|------|
| 開發者 | Peter Steinberger（奧地利） |
| 發布時間 | 2026 年 1 月 |
| 費用 | 開源免費（需搭配 AI 模型 API） |
| 支援平台 | Windows / macOS / Linux / 雲端 |
| 通訊管道 | LINE、Telegram、WhatsApp、Discord、Slack 等 22 個 |
| 官方技能 | 60+ 個（天氣、Email、日曆、自拍、語音通話等） |

龍蝦的能力範圍非常廣泛。在**通訊方面**，它可以在 LINE 和 Telegram 上跟你對話、回答問題。在**資訊蒐集方面**，它能幫你上網搜尋新聞、查天氣、讀取網頁內容。在**辦公方面**，它能管理你的 Email（讀取、搜尋、回覆）、查詢行事曆、新增行程提醒。更酷的是，它還有一些「娛樂性」的功能——比如用 AI 生成虛擬形象照片（龍蝦女友自拍）、每日自動推播 RSS 新聞摘要。進階功能方面，它能透過 Peekaboo 技術**遠端操作你的桌面**和瀏覽器，透過 Nodes 系統**同時控制多台電腦**，甚至透過 Twilio 服務**打電話給你**。

簡單來說，你能想到的事情，龍蝦幾乎都能幫你做。而且它有超過 60 個官方技能，即使做不到的事，社群也可能已經有人開發了對應的技能。

### 0.3.2 Google Antigravity — 你的 AI 工程師

如果 OpenClaw 是幫你「處理生活」的管家，那 Antigravity 就是幫你「建造東西」的工程師。

Google Antigravity 是 Google 在 2025 年 11 月隨著 Gemini 3 一起推出的 AI 開發環境。它長得很像 VS Code（程式設計師常用的編輯器），但最大的不同是：**你不需要會寫程式**。你只要用中文描述你想要什麼，Antigravity 就會自動幫你生成完整的應用程式。

| 項目 | 說明 |
|------|------|
| 開發者 | Google |
| 發布時間 | 2025 年 11 月 |
| 費用 | 個人免費（公開預覽版） |
| AI 模型 | Gemini 3.1 Pro、Gemini 3 Flash |
| 特色 | Agent Manager 多代理協作、內建瀏覽器 |

Antigravity 有兩個主要的操作介面。**Editor View（編輯器檢視）** 適合你想一邊看程式碼一邊修改的時候，AI 會即時幫你寫程式、補全和除錯。**Manager View（管理員檢視）** 更厲害——你可以同時派出多個 AI 代理，讓它們分頭處理不同任務。比如你可以同時讓一個 Agent 寫前端、一個 Agent 寫後端、一個 Agent 寫測試，它們會各自工作、互不干擾。

在這本書裡，Antigravity 扮演的角色主要是：幫你**快速建立工具和應用**。比如你需要一個網頁、需要一個小工具、需要自動化某個流程，Antigravity 可以在幾分鐘內幫你搞定。我們也會用它來輔助安裝和設定 OpenClaw——對，你沒看錯，我們會用 AI 來安裝 AI。

| 介面 | 用途 | 適合情境 |
|------|------|---------|
| **Editor View** | 即時寫程式、補全、除錯 | 你想一邊看一邊改 |
| **Manager View** | 派出多個 Agent 同時工作 | 你想同時處理多件事 |

### 0.3.3 Claude Code — 你的 AI 終端機特助

最後一位主角是 Claude Code，由 Anthropic 公司推出的終端機 AI 助手。

跟 Antigravity 的圖形化介面不同，Claude Code 住在**終端機**裡——也就是那個黑底白字的命令列視窗。你可能覺得這聽起來很「技術宅」，但其實不會。Claude Code 的使用方式非常直覺：你打開終端機、啟動 Claude Code，然後就像跟人聊天一樣，用中文告訴它你要做什麼。它會直接在你的電腦上執行操作——讀取檔案、修改程式碼、搜尋內容、自動 commit、建立 Pull Request——全部用對話完成。

| 項目 | 說明 |
|------|------|
| 開發者 | Anthropic |
| 費用 | 需要 API Key 或訂閱方案 |
| 操作方式 | 終端機 + VS Code / JetBrains 整合 |
| AI 模型 | Claude Opus 4.6 / Sonnet 4.6 |
| 特色 | 深度程式碼理解、Git 操作、Voice Mode 語音輸入 |

Claude Code 特別強大的地方在於**它真的能理解你的整個專案**。你問它「這個專案的結構是什麼？」它會把所有檔案讀一遍，然後用淺顯易懂的方式告訴你。你說「幫我把 config.json 裡的 port 改成 3000」，它就直接改好。你說「幫我 commit 這次的修改」，它就自動寫好 commit message、幫你提交。2026 年 3 月新增的 **Voice Mode** 更是一大亮點——你按住空白鍵用「說」的，Claude Code 就會聽你的語音指令去執行操作。

```bash
# 啟動 Claude Code
```

## 0.5 小結與展望

---

在這一章裡，我們一起走過了四個重要的觀念：

首先，我們了解了**自主代理 AI** 跟傳統聊天機器人的根本差異。聊天機器人是「你問它答」，自主代理是「你交代一次，它自己去完成所有事」。這個觀念非常重要，因為它決定了你接下來使用 AI 的方式——你不再是一個「提問者」，而是一個「指揮者」。

接著，我們回顧了 **AI Agent 四代演進**的歷程：從只能寫程式碼的第一代，到能操作瀏覽器的第二代，到能操作整個桌面的第三代，再到能跨平台、跨裝置、24 小時運行的第四代。OpenClaw 正是第四代 Agent 的代表作。

然後，我們認識了本書的**三個核心工具**：OpenClaw 是你的 AI 管家，負責日常生活的方方面面；Antigravity 是你的 AI 工程師，擅長快速建造應用程式；Claude Code 是你的 AI 終端機特助，精準又高效地操作你的電腦。三強聯手，無所不能。

最後，我們瀏覽了**全書的學習路線圖**——22 章加 4 篇附錄，從入門到進階，帶你從零基礎一路成長為全能的 AI 使用者。

在下一章（CH1），我們就要開始**動手準備環境和申請帳號**了。別擔心，每一步都會有詳細的截圖教學。就像做菜前先備料，我們會把所有需要的「食材」——Gmail、LINE Developer、AI API Key、ngrok 等等——全部準備齊全。備好料，後面炒菜才會順利！
